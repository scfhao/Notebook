在 Plan Mode 中，Claude 使用 [AskUserQuestion](https://code.claude.com/docs/zh-CN/settings#tools-available-to-claude) 来收集需求并在提出计划之前澄清您的目标。

## 切换模式

在会话模式下使用 Shift+Tab，这样会在不同的模式中循环切换。

或者启动新的Plan Mode会话：

```bash
claude --permission-mode plan
```

配置默认模式：

```json
// .claude/settings.json
{
  "permissions": {
    "defaultMode": "plan"
  }
}
```
