# SAST、DAST与RASP对比：应用安全测试方法比较

## 什么是SAST？

静态应用程序安全测试（SAST Static Application Security Testing）是一种白盒安全测试方法。SAST利用应用程序的静态源代码或二进制文件来识别漏洞。这意味着SAST工具会在应用程序未运行时对其代码进行操作。

开发人员使用 SAST 来检测代码中的各类安全风险，例如：跨站脚本攻击（XSS）、不安全的反序列化、缓冲区溢出以及其他 OWASP 漏洞。由于仅靠 SAST 无法识别特定运行时漏洞，开发人员通常需要将 SAST 与其他测试方法相结合，以实现全面的安全保障。

静态应用程序安全测试（SAST）可集成到持续集成/持续部署（CI/CD）流水线中，集成后即被称为“安全开发运维”（Secure DevOps）或开发安全运维（DevSecOps）。静态应用程序安全测试可通过自动化实现广泛扩展，能够实现覆盖静态应用程序安全测试技术的自动化测试，使其成为快速应对代码级风险的高效解决方案。

## 什么是动态应用程序安全测试（DAST）？

动态应用程序安全测试是一种黑盒测试方法。DAST 中“动态”一词表明，该方法会在应用程序运行时评估其安全性。与静态应用程序安全测试（SAST）不同，动态应用程序安全测试无需访问应用程序的源代码。相反，它会：

1. 模拟外部攻击者的行为。
2. 从外部测试应用程序，以识别漏洞，这些漏洞仅在运行时出现。

DAST 能够识别各类安全漏洞，例如拒绝服务（DoS）漏洞以及不安全的服务器配置。通过模拟真实的攻击场景，DAST 工具会评估应用程序对这些模拟威胁的响应情况。

通常，开发人员会在软件开发生命周期的后期阶段（通常是部署前）执行动态应用程序安全测试（DAST）。

## 常见静态应用程序安全测试方法

1. 模式匹配会在代码库中扫描已知的不安全编码实践模式。例如，使用弱加密算法或不安全的API调用。
2. 数据流C跟踪数据在应用程序中的流动方式。通过追踪从不可信输入路径到敏感操作的过程，它可以识别SQL注入或缓冲区溢出等漏洞。
3. 控制流分析可以分析应用程序的控制结构。例如，通过循环和条件语句来发现逻辑缺陷或竞争条件等潜在漏洞。
4. 自定义规则创建。许多工具允许开发者制定自定义规则以遵循编码最佳实践。以下是这些自定义规则的一些示例：
    * 标记SQL查询中任何未经过净化处理的输入用法。
    * 识别在未进行适当转义的情况下将用户提供的数据输出到浏览器的代码。
    * 突出显示易受攻击或已废弃函数的使用情况，例如 JavaScript 中的 eval() 或 C 语言中的 strcpy()。
    * 检测源代码中硬编码的 API 密钥和密码，并标记用户提供的数据缺少输入验证的所有实例。
5. 依赖项扫描。一些SAST工具会分析应用程序中使用的第三方库和框架，以识别依赖项中的漏洞。
6. 语义分析。通过解读代码的含义而非仅分析其结构，静态应用程序安全测试工具能够检测到不安全的配置或API滥用情况。
7. 机器学习模型：先进的静态应用程序安全测试工具结合机器学习算法，通过分析大型数据集中的模式来识别此前未知的漏洞。

## DAST 步骤

1. 扫描。扫描Web应用程序以发现入口点（如URL、表单和API）。此步骤可梳理出应用程序的结构，并识别潜在攻击面。
2. 攻击模拟。通过向应用程序发送精心构造的请求来模拟恶意活动。这些请求会尝试利用入口点，以此测试跨站脚本、跨站请求伪造等漏洞。
3. 漏洞检测。分析应用程序的响应以识别安全漏洞。它会评估应用程序在受到攻击时是否按预期运行。例如，可以注入恶意数据来检测SQL注入漏洞。
4. 报告生成。生成包含已检测漏洞和修复建议的报告。开发人员可利用报告中的结果修复已识别的问题。

现代DAST解决方案可整合AI驱动分析和实时数据集成等高级功能。它们能自动生成测试集，根据应用结构动态适配，并利用机器学习算法最大限度减少误报情况。

## 将 RASP 用作 SAST 和 DAST 的替代方案

运行时应用自我保护（RASP）是一种直接安装在应用运行所在服务器上的高级安全解决方案。

RASP 嵌入到应用程序的运行时环境中。这种集成使 RASP 能够分析应用程序的逻辑和数据。在分析过程中，它可以：

1. 异常行为发生时即可检测。
2. 立即拦截恶意活动

RASP 在保护应用程序免受绕过网络防御或在开发期间被遗漏的漏洞攻击方面尤为有效。

然而，对运行时应用自我保护（RASP）的过度自信可能会导致组织忽视安全编码实践。此外，由于运行时应用自我保护（RASP）直接在应用程序的运行时环境内运行，它可能会影响应用程序的性能。运行时应用自我保护（RASP）无法替代修复潜在漏洞的必要性，但在进行修复的同时，它能提供持续的保护。

通过将这些方法整合到CI/CD管道中并利用人工智能的最新进展，企业可以主动应对新出现的威胁。这些方法共同提供了一种全面的方式，从安全漏洞的角度保护现代应用程序的安全。
