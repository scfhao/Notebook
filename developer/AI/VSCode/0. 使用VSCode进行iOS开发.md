## 在 VSCode 上配置 iOS 开发环境

也适用于基于 VSCode 的诸多 AI IDE（如 Cursor、TRAE 等）。

1. 安装 Xcode Build Server

部署[Xcode Build Server](https://github.com/SolaWing/xcode-build-server)后将允许 sourcekit-LSP 在 Xcode 之外工作，因此您将获得所有功能，如跳转到定义、查看所有引用、调用树分析等……您在编辑代码时在 Xcode 中获得的几乎所有功能，您也可以在 Cursor 中获得。

```bash
brew install xcode-build-server
```

安装后可以执行下面命令来解决 VSCode 中代码报错：

```bash
xcode-build-server config -workspace *.xcworkspace -scheme <XXX> 

xcode-build-server config -project *.xcodeproj -scheme <XXX>
```

2. 安装 xcbeautify(非必要)

安装[xcbeautify](https://github.com/cpisciotta/xcbeautify)将在 Cursor 终端中漂亮地打印 xcodebuild 输出。

```bash
brew install xcbeautify
```

3. 安装 VSCode 插件

Swift，CodeLLDB，Sweetpad

Sweetpad 是让整个流程在 Xcode GUI 之外运行的关键。Sweetpad Sweetpad 为 xcodebuild CLI 封装了大量快捷方式（以及更多），并允许您像 Xcode 一样扫描目标、选择目标、构建和运行您的应用。除此之外，它还会为 Xcode Build Server 设置您的项目，以便您获得上述所有功能。

安装 Sweetpad 后，使用 CMD+SHIFT+P 打开命令面板并选择`SweetPad: Generate Build Server Config(buildServer.json)`。这将在您的目录根目录创建一个 buildServer.json，并允许 Xcode Build Server 与您的项目目录一起工作。

然后选择选择`SweetPad: Build & Run(Launch)`生成`.vscode/launch.json`。

完成后，点击构建并运行（从 Sweetpad 选项卡）。从那里，您可以浏览所有目标并在其中任何一个上点击运行。

使用 F5 连接调试器。

4. 设置热加载

* 添加依赖包[Inject](https://github.com/krzysztofzablocki/Inject.git)。
* 为 Debug 模式分别添加`-Xlinker -interposable`（分两行）`Other Linker Flags`。
* 安装Xcode注入[InjectionIII](https://github.com/johnno1962/InjectionIII/releases)。
* 新版Xcode需要新增一个用户定义的Build Settings `EMIT_FRONTEND_COMMAND_LINES`，值为`YES`。
