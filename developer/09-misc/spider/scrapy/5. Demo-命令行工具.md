# Scrapy 命令行工具

Scrapy 通过`scrapy`命令行工具被控制，后文以“Scrapy工具”称呼此命令行工具，为了于这个命令的子命令区分，我们称子命令为“命令”或“Scrapy命令”。

举个例子，在`scrapy startproject myproject`这个命令中，scrapy 是当前的命令行工具，startproject 是子命令。

## 配置设置

Scrapy 会从3个位置读取配置文件：

1. `/etc/scrapy.cfg`或`c:\scrapy\scrapy.cfg`(系统级)
2. `~/.config/scrapy.cfg`(`$XDG_CONFIG_HOME`)和`~/.scrapy.cfg`(`$HOME`)用于（用户级的）全局设置
3. 位于项目根目录中的`scrapy.cfg`文件（项目级）。

> 译者注：`~`在Unix、Linux、macOS 等系统中代表用户的`家目录`，在 macOS 中，家目录指`/Users/你的账户名/`这个目录。

如果不同级的配置有冲突，用户级的配置优先级高于系统级的，项目级的优先级又高于用户级的。

Scrapy 也支持通过环境变量进行配置：

* `SCRAPY_SETTINGS_MODULE`
* `SCRAPY_PROJECT`
* `SCRAPY_PYTHON_SHELL`

## 默认的 Scrapy 项目结果

Scrapy 项目默认的项目结果如下：

```
scrapy.cfg
myproject/
	__init__.py
	items.py
	middlewares.py
	pipelines.py
	settings.py
	spiders/
		__init__.py
		spider1.py
		spider2.py
		...
```

其中`scrapy.cfg`文件所在的目录被称为`项目根目录`,这个文件中的项目设置部分定义了当前 python 模块的名字，如下：

```scrapy.cfg
[settings]
default = myproject.settings
```

## 在项目之间分享根目录

项目根目录可以在多个项目之间共享，这种情况下，你需要在你的`scrapy.cfg`文件中的`settings`下面定义多个设置模块的别名：

```[settings]
default = myproject1.settings
project1 = myproject1.settings
project2 = myproject2.settings
```

默认情况，`scrapy`工具会使用`default`设置。可以通过定义`SCRAPY_PROJECT`环境变量来指定`scrapy`工作的项目。

```SHELL
// 这行命令打印 机器人名称
scrapy settings --get BOT_NAME
// 这是输出
Project 1 Bot
// 设置环境变量
export SCRAPY_PROJECT=project2
// 再次打印
scrapy settings --get BOT_NAME
// 输出
Project 2 Bot
```

## 使用 scrapy 工具

我们可以通过不加任何参数执行 Scrapy 工具，这样它就会打印一些使用帮助和可用的子命令：

```
Scrapy X.Y - no active project

Usage:
  scrapy <command> [options] [args]

Available commands:
  crawl         Run a spider
  fetch         Fetch a URL using the Scrapy downloader
[...]
```

### 创建项目

通常我们使用 scrapy 工具要做的第一件事是创建 Scrapy 项目

```SHELL
scrapy startporject myproject [project_dir]
```

这样就会在`project_dir`路径下创建一个 Scrapy 项目，如果没有指定`project_dir`，`project_dir`会和`myproject`一致。

下一步，进入新项目文件夹

```SHELL
cd project_dir
```

到这里，你就已经准备好使用`scrapy`命令来管理和控制你的项目了

### 控制项目

创建新爬虫：

```
scrapy genspider mydomain mydomain.com
```

## 可用的命令

这个小节包含一个可用的命令描述和示例，记住不论何时，你都可以通过运行如下命令来获取更多信息：

```SHELL
scrapy <command> -h
```

或者使用下面的命令查看全部可用命令：

```SHELL
scrapy -h
```

这些命令可用分为两类，一类是只能在 Scrapy 项目目录里使用的项目命令，另一类是可用在 Scrapy 项目外使用的全局命令。

全局命令：

* `startproject`
* `genspider`
* `settings`
* `runspider`
* `shell`
* `fetch`
* `view`
* `version`

项目命令：

* `crawl`
* `check`
* `list`
* `edit`
* `parse`
* `bench`

### startproject

语法：`scrapy startproject <project_name> [project_dir]`

在`project_dir`下创建一个名为`project_name`的 Scrapy 项目。如果`project_dir`未指定，则与`project_name`一致。

示例：

```SHELL
scrapy startproject myproject
```

### genspider

语法：`scrapy genspider [-t template] <name> <domain or URL>`

使用示例：

```SHELL
$ scrapy genspider -l
Available templates:
  basic
  crawl
  csvfeed
  xmlfeed

$ scrapy genspider example example.com
Created spider 'example' using template 'basic'

$ scrapy genspider -t crawl scrapyorg scrapy.org
Created spider 'scrapyorg' using template 'crawl'
```

### crawl

语法：`scrapy crawl <spider>`

使用爬虫开始抓取任务。

支持的选项：

* `-h, --help`：展示帮助信息
* `-a NAME=VALUE`：设置蜘蛛参数
* `--output FILE, -o FILE`：追加抓取到的数据项到文件（使用 - 则输出到 stdout），后面跟上冒号可以指定文件格式，如`-o FILE:FORMAT`
* `--overwrite-output FILE, -O FILE`：重复抓取的数据输出到文件，覆盖已存在的输出文件内容，也支持加冒号指定文件格式

使用示例：

```SHELL
$ scrapy crawl myspider
[ ... myspider starts crawling ... ]

$ scrapy crawl -o myfile:csv myspider
[ ... myspider starts crawling and appends the result to the file myfile in csv format ... ]

$ scrapy crawl -O myfile:json myspider
[ ... myspider starts crawling and saves the result in myfile in json format overwriting the original content... ]

$ scrapy crawl -o myfile -t csv myspider
[ ... myspider starts crawling and appends the result to the file myfile in csv format ... ]
```

### check

语法：`scrapy check [-l] <spider>`

执行合同检查

使用示例：

```SHELL
$ scrapy check -l
first_spider
  * parse
  * parse_item
second_spider
  * parse
  * parse_item

$ scrapy check
[FAILED] first_spider:parse_item
>>> 'RetailPricex' field is missing

[FAILED] first_spider:parse
>>> Returned 92 requests, expected 0..4
```

### list

语法：`scrapy list`

列出当前项目中全部可用的爬虫。一个爬虫作为一行输出

使用示例：

```SHELL
scrapy list
spider1
spider2
```

### edit

语法：`scrapy edit <spider>`

使用`EDITOR`环境变量中定义的编辑器编辑给定的爬虫，如果未设置这个环境变量，则使用设置中的`EDITOR`。

使用示例：

```SHELL
scrapy edit spider1
```

这里只是提供一种快捷的编辑入口，你依然可以自由选择编辑器。

### fetch

语法：`scrapy fetch <url>`

使用 Scrapy 下载器下载给定的 URL 并把内容写到标准输出。

支持的选项：

* `--spider=SPIDER`：绕过蜘蛛的自动检测，强制使用指定蜘蛛
* `--headers`：打印HTTP响应头，而不是响应体
* `--no-redirect`：不追踪 HTTP 3xx 重定向

用法示例：

```SHELL
$ scrapy fetch --nolog http://www.example.com/some/page.html
[ ... html content here ... ]

$ scrapy fetch --nolog --headers http://www.example.com/
{'Accept-Ranges': ['bytes'],
 'Age': ['1263   '],
 'Connection': ['close     '],
 'Content-Length': ['596'],
 'Content-Type': ['text/html; charset=UTF-8'],
 'Date': ['Wed, 18 Aug 2010 23:59:46 GMT'],
 'Etag': ['"573c1-254-48c9c87349680"'],
 'Last-Modified': ['Fri, 30 Jul 2010 15:30:18 GMT'],
 'Server': ['Apache/2.2.3 (CentOS)']}
```

### view

语法：`scrapy view <url>`

在浏览器中打开 Scrapy 爬虫看到的页面。有时候爬虫看到的页面和普通用户看到的不一样，用这个命令可以查看爬虫看到的样子，确认是否和你预期的一样。

支持的选项：

* `--spider=SPIDER`：绕过蜘蛛的自动检测，强制使用指定蜘蛛
* `--no-redirect`：不追踪 HTTP 3xx 重定向

使用示例：

```SHELL
$ scrapy view http://www.example.com/some/page.html
[ ... browser starts ... ]
```

### shell

语法：`scrapy shell [url]`

从给定的 URL 启动 scrapy shell。也支持 UNIX 式的本地文件地址，可以是`./`或`../`开头的相对路径，也可以是绝对路径。

支持的选项：

* `--spider=SPIDER`：绕过蜘蛛的自动检测，强制使用指定蜘蛛
* `-c code`：在 shell 中测试 code，打印测试结果
* `--no-redirect`：不追踪 HTTP 3xx 重定向，只对从命令行传入的 URL 生效

使用示例：

```SHELL
$ scrapy shell http://www.example.com/some/page.html
[ ... scrapy shell starts ... ]

$ scrapy shell --nolog http://www.example.com/ -c '(response.status, response.url)'
(200, 'http://www.example.com/')

# shell follows HTTP redirects by default
$ scrapy shell --nolog http://httpbin.org/redirect-to?url=http%3A%2F%2Fexample.com%2F -c '(response.status, response.url)'
(200, 'http://example.com/')

# you can disable this with --no-redirect
# (only for the URL passed as command line argument)
$ scrapy shell --no-redirect --nolog http://httpbin.org/redirect-to?url=http%3A%2F%2Fexample.com%2F -c '(response.status, response.url)'
(302, 'http://httpbin.org/redirect-to?url=http%3A%2F%2Fexample.com%2F')
```

### parse

语法：`scrapy parse <url> [options]`

加载给定 URL 并用爬虫解析它的页面，使用传递给`--callback`选项的函数或默认的`parse`函数解析。

支持的选项：

* `--spider=SPIDER`：绕过蜘蛛的自动检测，强制使用指定蜘蛛
* `--a NAME=VALUE`：爬虫参数
* `--callback, -c`：爬虫处理响应的回调方法
* `--meta, -m`：将传递给回调函数的请求元，必须是合法的JSON字符串，如：-meta='{"foo":"bar"}'
* `--cbkwargs`：将传递给回调函数的附加关键字参数，必须是合法的JSON字符串，如：-cbkwargs='{"foo":"bar"}'
* `--pipelines`：通过 pipelines 处理数据项
* `--rules, -r`：使用 CrawlSpider 规则发现用于解析响应的回调（即 spider 方法
* `--noitems`：不显示抓取的项目
* `--nolinks`：不显示提取的链接
* `--nocolour`：避免使用 pygments 为输出着色
* `--depth, -d`：递归跟踪请求的深度级别（默认：1）
* `--verbose, -v`：显示每个深度等级的信息
* `--output, -o`：输出抓取的项目到文件

使用示例：

```SHELL
$ scrapy parse http://www.example.com/ -c parse_item
[ ... scrapy log lines crawling example.com spider ... ]

>>> STATUS DEPTH LEVEL 1 <<<
# Scraped Items  ------------------------------------------------------------
[{'name': 'Example item',
 'category': 'Furniture',
 'length': '12 cm'}]

# Requests  -----------------------------------------------------------------
[]
```

### settings

语法：`scrapy settings [options]`

获取 Scrapy 的设置的值

使用示例：

```SHELL
$ scrapy settings --get BOT_NAME

$ scrapy settings --get DOWNLOAD_DELAY
```

使用示例：


### version

语法：`scrapy version [-v]`

打印 Scrapy 版本。如果加上`-v`参数，还会打印 Python、Twisted 和 Platform 信息，这对错误报告很有用。

### bench

语法：`scrapy bench`

运行快速基准测试

## 自定义项目命令

你也可以使用`COMMANDS_MODULE`设置来添加自定义的项目命令。

### COMMANDS_MODULE

默认值：''（空字符串）

用于查找自定义 Scrapy 命令的模块。用于为 Scrapy 项目添加自定义命令。

示例：

```
COMMANDS_MODULE = "mybot.commands"
```

### 通过 setup.py 注册命令入口点

你也可以在外部库`setup.py`文件的入口处添加`scray.commands`部分，从而从外部库中添加 Scrapy 命令。

下面的示例添加了`my_command`命令：

```Python
from setuptools import setup, find_packages

setup(
    name="scrapy-mymodule",
    entry_points={
        "scrapy.commands": [
            "my_command=my_scrapy_module.commands:MyCommand",
        ],
    },
)
```
