在大多数的情况下，我们的爬虫还需要爬取网页里的超链接所链接的网页的内容，比如在示例网页中，有一个指向下一页的超链接，如下：

```HTML
<ul class="pager">
    <li class="next">
        <a href="/page/2/">Next <span aria-hidden="true">&rarr;</span></a>
    </li>
</ul>
```

我们可以尝试在 shell 中获取里面的超链接

```SHELL
>>> response.css('li.next a').get()
'<a href="/page/2/">Next <span aria-hidden="true">→</span></a>'
```

得到的是超链接，但我们只想获取它的`href`属性。为此，Scrapy 支持一个 CSS 扩展来获取属性值：

```SHELL
>>> response.css('li.next a::attr(href)').get()
'/page/2/'
```

或者使用`attrib`属性也可以获取：

```SHELL
>>> response.css('li.next a').attrib['href']
'/page/2/'
```

现在，我们可以把我们的爬虫修改为可以跟踪超链接进入下一页，并从下一页获取数据：

```Python
import scrapy

class QuotesSpider(scrapy.Spider):
    name = "quotes"
    start_urls = [
        "https://quotes.toscrape.com/page/1/",
    ]

    def parse(self, response):
        for quote in response.css("div.quote"):
            yield {
                "text": quote.css("span.text::text").get(),
                "author": quote.css("small.author::text").get(),
                "tags": quote.css("div.tags a.tag::text").getall(),
            }

        next_page = response.css("li.next a::attr(href)").get()
        if next_page is not None:
            next_page = response.urljoin(next_page)
            yield scrapy.Request(next_page, callback=self.parse)
```

现在的`parse()`方法在取出数据后，会查看是否存在到下一页的链接，由于连接（/page/2/）是相对地址，所以使用`urljoin()`方法构建成完整的绝对URL，然后生成一个获取下一页的新请求，并把自己的`parse()`方法注册为新请求的回调，这样一页接着一页就可以把所有页面的数据都爬下来。

你在这里看到的就是 Scrapy 追踪链接的机制：当你在回调方法中生成一个请求后，Scrapy 就会启动这个请求，并在请求结束后调用注册的回调函数。

这样，你就可以基于你定义的追踪链接的规则来构建复杂的爬虫，根据访问的不同的页面取出不同类型的数据。

## 创建请求的简写方式

你可以使用`response.follow`作为创建请求对象的简写方式：

```Python
import scrapy

class QuotesSpider(scrapy.Spider):
    name = "quotes"
    start_urls = [
        "https://quotes.toscrape.com/page/1/",
    ]

    def parse(self, response):
        for quote in response.css("div.quote"):
            yield {
                "text": quote.css("span.text::text").get(),
                "author": quote.css("span small::text").get(),
                "tags": quote.css("div.tags a.tag::text").getall(),
            }

        next_page = response.css("li.next a::attr(href)").get()
        if next_page is not None:
            yield response.follow(next_page, callback=self.parse)
```

不同于`scrapy.Request`，`response.follow`支持相对 URL，所以不需要调用`urljoin`，相同的是这两个方法都是返回 Request 对象，都需要`yield`。

你也可以只传给`response.follow`一个选择器来代替字符串，这时选择器需要定位到属性：

```Python
// 注意下面这行，选择器后面没加 .get() ，加了 .get() 得到的就是字符串了
for href in response.css("ul.pager a::attr(href)"):
    yield response.follow(href, callback=self.parse)
```

在处理`<a>`元素时，`response.follow`自动使用`<a>`标签的`href`属性，所以上面的代码还可以简写为：

```Python
for a in response.css("ul.pager a"):
    yield response.follow(a, callback=self.parse)
```

如果是像上面这样通过遍历来创建多个请求，可以使用`response.follow_all`代替：

```Python
anchors = response.css("ul.pager a")
yield from response.follow_all(anchors, callback=self.parse)
```

进一步，还可以再简写成：

```Python
yield from response.follow_all(css="ul.pager a", callback=self.parse)
```

## 更多示例

一个有多个回调函数和链接追踪的示例，爬取作者信息

```Python
import scrapy

class AuthorSpider(scrapy.Spider):
    name = "author"

    start_urls = ["https://quotes.toscrape.com/"]

    def parse(self, response):
        author_page_links = response.css(".author + a")
        yield from response.follow_all(author_page_links, self.parse_author)

        pagination_links = response.css("li.next a")
        yield from response.follow_all(pagination_links, self.parse)

    def parse_author(self, response):
        def extract_with_css(query):
            return response.css(query).get(default="").strip()

        yield {
            "name": extract_with_css("h3.author-title::text"),
            "birthdate": extract_with_css(".author-born-date::text"),
            "bio": extract_with_css(".author-description::text"),
        }
```

需要说明的是，即使这个网站上有多个 quotes 来自同一个作者，也不需要担心爬虫会多次访问同一个作者页面。Scrapy 默认会排除已经访问过的地址，避免由于编程失误导致的访问服务器次数过多。可以通过设置`DUPEFILTER_CLASS`来配置这个行为。

希望你现在已经很好地理解了如何使用 Scrapy 的跟随链接和回调机制。
