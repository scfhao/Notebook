在命令行中，你可以通过使用`-a`选项来向你的蜘蛛传递参数：

```SHELL
scrapy crawl quotes -O quotes-humor.json -a tag=humor
```

这些参数默认会传给蜘蛛的`__init__`方法成为蜘蛛的属性。

在这个示例中，可以通过`self.tag`使用提供的`tag`值，这样基于传进来的参数生成 URL，就可以让蜘蛛只爬取指定 tag 的 quotes。

```Python
import scrapy

class QuotesSpider(scrapy.Spider):
    name = "quotes"

    def start_requests(self):
        url = "https://quotes.toscrape.com/"
        tag = getattr(self, "tag", None)
        if tag is not None:
            url = url + "tag/" + tag
        yield scrapy.Request(url, self.parse)

    def parse(self, response):
        for quote in response.css("div.quote"):
            yield {
                "text": quote.css("span.text::text").get(),
                "author": quote.css("small.author::text").get(),
            }

        next_page = response.css("li.next a::attr(href)").get()
        if next_page is not None:
            yield response.follow(next_page, self.parse)
```

当传给蜘蛛的参数是`tag=humor`时，它访问的 URL 就会变成`https://quotes.toscrape.com/tag/humor`。
