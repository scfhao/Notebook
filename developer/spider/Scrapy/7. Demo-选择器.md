在进行网页搜刮时，最常见的任务就是从 HTML 源中提取数据。有几种库可以实现这一目的，例如:

* 在 Python 程序员中，[BeautifulSoup](https://www.crummy.com/software/BeautifulSoup/)是一个非常流行的网络搜刮库，它能根据 HTML 代码的结构构建 Python 对象，还能很好地处理不良标记，但它有一个缺点：速度很慢。
* [lxml](https://lxml.de/)是一个 XML 解析库（也能解析 HTML），其 API 基于`ElementTree`。(lxml 不是 Python 标准库的一部分）。

Scrapy 自带提取数据的机制。它们被称为选择器，因为它们"选择"HTML 文档中由[XPath](https://www.w3.org/TR/xpath/all/)或[CSS](https://www.w3.org/TR/selectors)表达式指定的某些部分。

`XPath`是一种在 XML 文档中选择节点的语言，也可用于 HTML。CSS 是一种在 HTML 文档中应用样式的语言。它定义了将这些样式与特定 HTML 元素关联的选择器。

> Scrapy 选择器是[parsel](https://parsel.readthedocs.io/en/latest/)库的一个瘦型封装；该封装的目的是更好地与 Scrapy 响应对象集成。 

> `parsel`是一个独立的网络搜刮库，无需 Scrapy 即可使用。它以 lxml 库为引擎，并在 lxml API 的基础上实现了简单的 API。这意味着 Scrapy 选择器的速度和解析精度与 lxml 非常接近。

## 使用选择器

### 构造选择器

响应对象会在`.selector`属性上显示一个`Selector`实例：

```SHELL
>>> response.selector.xpath("//span/text()").get()
'good'
```

使用 XPath 和 CSS 查询响应非常普遍，因此响应中又多了两个快捷方式：`response.xpath()`和`response.css()`：

```SHELL
>>> response.xpath("//span/text()").get()
'good'
>>> response.css("span::text").get()
'good'
```

Scrapy 选择器是`Selector`类的实例，通过传递`TextResponse`对象或作为字符串的标记（文本参数）来构建。

通常不需要手动构建 Scrapy 选择器：Spider 回调中提供了`response`对象，因此在大多数情况下，使用`response.css()`和`response.xpath()`快捷方式会更方便。使用`response.selector`或这些快捷方式之一，还能确保响应体只被解析一次。

但如果需要，也可以直接从文本构建`Selector`。

```SHELL
>>> from scrapy.selector import Selector
>>> body = "<html><body><span>good</span></body></html>"
>>> Selector(text=body).xpath("//span/text()").get()
'good'
```

从响应构建 -`HtmlResponse`是`TextResponse`子类之一：

```SHELL
>>> from scrapy.selector import Selector
>>> from scrapy.http import HtmlResponse
>>> response = HtmlResponse(url="http://example.com", body=body, encoding="utf-8")
>>> Selector(response=response).xpath("//span/text()").get()
'good'
```

`Selector`会根据输入类型自动选择最佳解析规则（XML 与 HTML）。

### 使用选择器

为了解释如何使用选择器，我们将使用`Scrapy shell`（提供交互式测试），Scrapy 文档服务器中有一个示例页面：

[示例页面网址](https://docs.scrapy.org/en/latest/_static/selectors-sample1.html)

为完整起见，下面是完整的 HTML 代码：

```HTML
<!DOCTYPE html>

<html>
  <head>
    <base href='http://example.com/' />
    <title>Example website</title>
  </head>
  <body>
    <div id='images'>
      <a href='image1.html'>Name: My image 1 <br /><img src='image1_thumb.jpg' alt='image1'/></a>
      <a href='image2.html'>Name: My image 2 <br /><img src='image2_thumb.jpg' alt='image2'/></a>
      <a href='image3.html'>Name: My image 3 <br /><img src='image3_thumb.jpg' alt='image3'/></a>
      <a href='image4.html'>Name: My image 4 <br /><img src='image4_thumb.jpg' alt='image4'/></a>
      <a href='image5.html'>Name: My image 5 <br /><img src='image5_thumb.jpg' alt='image5'/></a>
    </div>
  </body>
</html>
```

首先，让我们打开 shell：

```SHELL
scrapy shell https://docs.scrapy.org/en/latest/_static/selectors-sample1.html
```

然后，在 shell 加载后，您就可以将响应作为`response`shell 变量使用，并在`response.selector`属性中使用其附加的选择器。

由于我们处理的是 HTML，因此选择器会自动使用 HTML 解析器。

因此，通过查看该页面的[HTML 代码](https://docs.scrapy.org/en/latest/topics/selectors.html#topics-selectors-htmlcode)，让我们构建一个 XPath 来选择标题标记内的文本：

```SHELL
>>> response.xpath("//title/text()")
[<Selector query='//title/text()' data='Example website'>]
```

要实际提取文本数据，必须调用选择器`.get()`或`.getall()`方法，如下所示：

```SHELL
>>> response.xpath("//title/text()").getall()
['Example website']
>>> response.xpath("//title/text()").get()
'Example website'
```

`.get()`总是返回一个单一结果；如果有多个匹配项，则返回第一个匹配项的内容；如果没有匹配项，则返回 None。`.getall()`返回一个包含所有结果的列表。

请注意，CSS 选择器可以使用 CSS3 伪元素选择文本或属性节点：

```SHELL
>>> response.css("title::text").get()
'Example website'
```

如您所见，`.xpath()`和`.css()`方法返回一个`SelectorList`实例，这是一个新选择器列表。该 API 可用于快速选择嵌套数据：

```SHELL
>>> response.css("img").xpath("@src").getall()
['image1_thumb.jpg',
'image2_thumb.jpg',
'image3_thumb.jpg',
'image4_thumb.jpg',
'image5_thumb.jpg']
```

如果只想提取第一个匹配的元素，可以调用选择器`.get()`(或之前 Scrapy 版本常用的别名`.extract_first()`）：

```SHELL
>>> response.xpath('//div[@id="images"]/a/text()').get()
'Name: My image 1 '
```

如果没有找到元素，则返回`None`：

```SHELL
>>> response.xpath('//div[@id="not-exists"]/text()').get() is None
True
```

可以提供一个默认返回值作为参数，用来代替`None`：

```SHELL
>>> response.xpath('//div[@id="not-exists"]/text()').get(default="not-found")
'not-found'
```

还可以使用`Selector`的`.attrib`属性来查询属性，代替使用`'@src'`XPath：

```SHELL
>>> [img.attrib["src"] for img in response.css("img")]
['image1_thumb.jpg',
'image2_thumb.jpg',
'image3_thumb.jpg',
'image4_thumb.jpg',
'image5_thumb.jpg']
```

作为快捷方式，`.attrib`也可直接用于 SelectorList；它会返回第一个匹配元素的属性：

```SHELL
>>> response.css("img").attrib["src"]
'image1_thumb.jpg'
```

当预期只有一个结果时，例如按 ID 选择或在网页上选择唯一元素时，这种方法最有用：

```SHELL
>>> response.css("base").attrib["href"]
'http://example.com/'
```

现在，我们要获取基本 URL 和一些图片链接：

```SHELL
>>> response.xpath("//base/@href").get()
'http://example.com/'

>>> response.css("base::attr(href)").get()
'http://example.com/'

>>> response.css("base").attrib["href"]
'http://example.com/'

>>> response.xpath('//a[contains(@href, "image")]/@href').getall()
['image1.html',
'image2.html',
'image3.html',
'image4.html',
'image5.html']

>>> response.css("a[href*=image]::attr(href)").getall()
['image1.html',
'image2.html',
'image3.html',
'image4.html',
'image5.html']

>>> response.xpath('//a[contains(@href, "image")]/img/@src').getall()
['image1_thumb.jpg',
'image2_thumb.jpg',
'image3_thumb.jpg',
'image4_thumb.jpg',
'image5_thumb.jpg']

>>> response.css("a[href*=image] img::attr(src)").getall()
['image1_thumb.jpg',
'image2_thumb.jpg',
'image3_thumb.jpg',
'image4_thumb.jpg',
'image5_thumb.jpg']
```

### CSS选择器的扩展

根据 W3C 标准，[CSS 选择器](https://www.w3.org/TR/selectors-3/#selectors)不支持选择文本节点或属性值。但在网络搜索中，选择这些内容是非常有必要的，因此 Scrapy (parsel) 实现了一些非标准的伪元素（non-standard pseudo-elements）：

* 使用`::text`选择文本元素
* 使用`::attr(name)`选择属性值，其中的 name 是你想要的属性的名称

> 这些伪元素是 Scrapy/Parsel 特有的。它们很可能无法与其他库（如 lxml 或 PyQuery）一起使用。

示例：

`title::text`选择后代`<title>`元素的子文本节点：

```SHELL
>>> response.css("title::text").get()
'Example website'
```

`*::text`会选择当前选择器上下文的所有后代文本节点：

```SHELL
>>> response.css("#images *::text").getall()
['\n   ',
'Name: My image 1 ',
'\n   ',
'Name: My image 2 ',
'\n   ',
'Name: My image 3 ',
'\n   ',
'Name: My image 4 ',
'\n   ',
'Name: My image 5 ',
'\n  ']
```

`foo::text`如果`foo`元素存在，但不包含文本（即文本为空），则不返回结果：

```SHELL
response.css("img::text").getall()
[]

This means ``.css('foo::text').get()`` could return None even if an element
exists. Use ``default=''`` if you always want a string:
```

```SHELL
>>> response.css("img::text").get()
>>> response.css("img::text").get(default="")
''
```

`a::attr(href)`选择后代链接的 href 属性值：

```SHELL
>>> response.css("a::attr(href)").getall()
['image1.html',
'image2.html',
'image3.html',
'image4.html',
'image5.html']
```

> 另见：[选择元素属性](https://docs.scrapy.org/en/latest/topics/selectors.html#selecting-attributes)

> 您不能将这些伪元素链起来。但在实践中，这样做意义不大：文本节点没有属性，而属性值本来就是字符串值，没有子节点。

### 嵌套选择器

选择方法（`.xpath()`或 `.css()`）会返回相同类型选择器的列表，因此你也可以调用这些选择器的选择方法。下面是一个例子：

```SHELL
>>> links = response.xpath('//a[contains(@href, "image")]')
>>> links.getall()
['<a href="image1.html">Name: My image 1 <br><img src="image1_thumb.jpg" alt="image1"></a>',
'<a href="image2.html">Name: My image 2 <br><img src="image2_thumb.jpg" alt="image2"></a>',
'<a href="image3.html">Name: My image 3 <br><img src="image3_thumb.jpg" alt="image3"></a>',
'<a href="image4.html">Name: My image 4 <br><img src="image4_thumb.jpg" alt="image4"></a>',
'<a href="image5.html">Name: My image 5 <br><img src="image5_thumb.jpg" alt="image5"></a>']

>>> for index, link in enumerate(links):
...     href_xpath = link.xpath("@href").get()
...     img_xpath = link.xpath("img/@src").get()
...     print(f"Link number {index} points to url {href_xpath!r} and image {img_xpath!r}")
...
Link number 0 points to url 'image1.html' and image 'image1_thumb.jpg'
Link number 1 points to url 'image2.html' and image 'image2_thumb.jpg'
Link number 2 points to url 'image3.html' and image 'image3_thumb.jpg'
Link number 3 points to url 'image4.html' and image 'image4_thumb.jpg'
Link number 4 points to url 'image5.html' and image 'image5_thumb.jpg'
```

### 选择元素属性

获取属性值有几种方法。首先，可以使用 XPath 语法：

```SHELL
>>> response.xpath("//a/@href").getall()
['image1.html', 'image2.html', 'image3.html', 'image4.html', 'image5.html']
```

XPath 语法有几个优点：它是一种标准的 XPath 特性，而且`@attributes`可用于 XPath 表达式的其他部分--例如，可以通过属性值进行筛选。

Scrapy 还提供了 CSS 选择器的扩展（`::attr(...)`），可以获取属性值：

```SHEL
>>> response.css("a::attr(href)").getall()
['image1.html', 'image2.html', 'image3.html', 'image4.html', 'image5.html']
```

除此之外，Selector 还有一个`.attrib`属性。如果您希望在 Python 代码中查找属性，而不使用 XPaths 或 CSS 扩展，可以使用它：

```SHELL
>>> [a.attrib["href"] for a in response.css("a")]
['image1.html', 'image2.html', 'image3.html', 'image4.html', 'image5.html']
```

该属性也可用于 SelectorList；它会返回一个包含第一个匹配元素属性的字典。当希望选择器只给出一个结果时（如按元素 ID 选择或在页面上选择唯一元素时），使用该属性非常方便：

```SHELL
>>> response.css("base").attrib
{'href': 'http://example.com/'}
>>> response.css("base").attrib["href"]
'http://example.com/'
```

空 SelectorList 的`.attrib`属性为空：

```SHELL
>>> response.css("foo").attrib
{}
```

### 使用带正则表达式的选择器

`Selector`还有一个`.re()`方法，用于使用正则表达式提取数据。不过，与使用`.xpath()`或`.css()`方法不同，`.re()`返回的是一个字符串列表。因此你不能构造嵌套的`.re()`调用。

下面是一个用于从上述 HTML 代码中提取图片名称的示例：

```SHELL
>>> response.xpath('//a[contains(@href, "image")]/text()').re(r"Name:\s*(.*)")
['My image 1 ',
'My image 2 ',
'My image 3 ',
'My image 4 ',
'My image 5 ']
```

对于`.re()`，还有一个简写，名为`.re_first()`。使用它可以只提取第一个匹配字符串：

```SHELL
>>> response.xpath('//a[contains(@href, "image")]/text()').re_first(r"Name:\s*(.*)")
'My image 1 '
```

### `extract()`和`extract_first()`

如果你是 Scrapy 的有经验用户，你可能对`.extract()`和`.extract_first()`选择器方法并不陌生。许多博文和教程也在使用它们。Scrapy 仍然支持这些方法，目前还没有计划淘汰它们。

不过，Scrapy 使用文档现在使用`.get()`和`.getall()`方法编写。我们认为这些新方法使代码更加简洁易读。

下面的示例展示了这些方法如何相互映射。

1. `SelectorList.get()`与`SelectorList.extract_first()`相同：

```SHELL
>>> response.css("a::attr(href)").get()
'image1.html'
>>> response.css("a::attr(href)").extract_first()
'image1.html'
```

2. `SelectorList.getall()`与`SelectorList.extract()`相同:

```SHELL
>>> response.css("a::attr(href)").getall()
['image1.html', 'image2.html', 'image3.html', 'image4.html', 'image5.html']
>>> response.css("a::attr(href)").extract()
['image1.html', 'image2.html', 'image3.html', 'image4.html', 'image5.html']
```

3. `Selector.get()`与`Selector.extract()`相同:

```SHELL
>>> response.css("a::attr(href)")[0].get()
'image1.html'
>>> response.css("a::attr(href)")[0].extract()
'image1.html'
```

4. 为了保持一致性，还可以使用`Selector.getall()`，它返回的是一个列表：

```SHELL
>>> response.css("a::attr(href)")[0].getall()
['image1.html']
```

因此，主要区别在于`.get()`和`.getall()`方法的输出更可预测：`.get()`总是返回单一结果，`.getall()`总是返回所有提取结果的列表。而使用`.extract()`方法时，一个结果是否是一个列表并不总是很明显:要获得单个结果，应调用`.extract()`或`.extract_first()`方法。
