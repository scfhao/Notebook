最简单的保存爬取的数据的方法是使用`Feed exports`，通过下面的命令：

```SHELL
scrapy crawl quotes -O quotes.json
```

这样会生成一个`quotes.json`文件包含爬到的序列化为 JSON 的数据。

命令中的`-O`选项会覆盖已存在的文件；改为`-o`则是在已存在的文件中追加新的内容。然而，追加内容到 JSON 文件会导致文件中的 JSON 格式不合法。需要追加时，可以考虑使用不同的序列化格式，比如 JSON Lines：

```SHELL
scrapy crawl quotes -o quotes.jsonl
```

JSON Lines 格式像流一样，你可以轻易的在内容后面追加新的记录，并且运行多次也不会产生 JSON 格式那种问题。同时，每条记录是单独的一行，这样处理比较大的文件时，也不需要把整个文件都加载到内存中，还有像 jq 这样的命令行工具可以使用。
