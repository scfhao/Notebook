互联网上的信息大多以网页形式展现，那么如何从网页中获取我们想要的数据呢？

最好的学习如何使用 Scrapy 获取数据的方法是尝试使用 Scrapy shell 选择器：

```SHELL
scrapy shell 'https://quotes.toscrape.com/page/1/'
```

> 记住在命令行中运行 Scrapy shell 时应总是把 url 用引号包起来，否则当 url 中包含参数时（例如`&`符号）时不能正常工作。

在 Windows 上，这里用双引号。

```DOS
scrapy shell "https://quotes.toscrape.com/page/1/"
```

退出 Scrapy shell 的方法：

```SHELL
quit()
```

通过 shell，尝试在响应中使用 CSS 选择元素。

```SHELL
>>> response.css("title")
[<Selector query='descendant-or-self::title' data='<title>Quotes to Scrape</title>'>]
```

运行`response.css('title')`的结果是一个名为 "SelectorList "的列表式对象，它代表了一个围绕 XML/HTML 元素的选择器对象列表，允许你运行进一步的查询来细化选择或提取数据。

如果想获取到上面的 title 标签的文本，可以：

```SHELL
>>> response.css("title::text").getall()
['Quotes to Scrape']
```

这里有两个地方需要注意一下，一是我们在 CSS 查询中加了`::text`，代表我们只想获取`<title>`标签元素中的文本。如果不指定`::text`，我们得到的就是完整的标题元素，包括标签。

另一个地方是`.getall()`的结果是一个列表：选择器可能返回多于一个的结果，如果你只需要里面的第一个，可以这样：

```SHELL
>>> response.css("title::text").get()
'Quotes to Scrape'
```

和下面这个是等效的，但是有个区别是使用下标序号访问数组元素时，会有数组越界的问题，而直接用`get`不会，另外如果结果不存在时，`get`返回的是`None`。

```SHELL
>>> response.css("title::text")[0].get()
'Quotes to Scrape'
```

除`getall()`和`get()`方法外，可以通过`re()`方法使用正则表达式获取数据：

```SHELL
>>> response.css("title::text").re(r"Quotes.*")
['Quotes to Scrape']
>>> response.css("title::text").re(r"Q\w+")
['Quotes']
>>> response.css("title::text").re(r"(\w+) to (\w+)")
['Quotes', 'Scrape']
```

可以使用`view(response)`命令调用浏览器打开当前抓取到的页面，然后使用浏览器提供的开发者工具来查找合适的 CSS 选择器。

## XPath: 简介

除 CSS 外，Scrapy 选择器也支持使用 XPath 表达式：

```SHELL
>>> response.xpath("//title")
[<Selector query='//title' data='<title>Quotes to Scrape</title>'>]
>>> response.xpath("//title/text()").get()
'Quotes to Scrape'
```

XPath 表达式非常强大，是 Scrapy 选择器的基石。实际上，CSS 选择器在底层会转换成 XPath。

掌握选择器的用法后，就可以在爬虫的 parse 方法中从网页中获取想要的数据了：

```Python
import scrapy

class QuotesSpider(scrapy.Spider):
    name = "quotes"
    start_urls = [
        "https://quotes.toscrape.com/page/1/",
        "https://quotes.toscrape.com/page/2/",
    ]

    def parse(self, response):
        for quote in response.css("div.quote"):
            yield {
                "text": quote.css("span.text::text").get(),
                "author": quote.css("small.author::text").get(),
                "tags": quote.css("div.tags a.tag::text").getall(),
            }
```
