## 2.1 单片机的内部资源

作为单片机用户，单片机提供给我们可使用的东西。总结起来，主要是三大资源：

* Flash: 程序存储空间，早期单片机是OTPROM(One Time Programmable Read-Only Memory)。
* RAM: 数据存储空间。
* SFR: 特殊功能寄存器。

通常我们一说到 51 单片机，指的是兼容 Intel MCS-51 体系架构的一系列单片机，而 51 是它的一个通俗的简称。

## 2.2 单片机最小系统

单片机最小系统，也叫做单片机最小应用系统，是指用最少的原件组成单片机可以工作的系统。单片机最小系统的三要素就是电源、晶振、复位电路。

### 2.2.1 电源

目前主流单片机的电源分别为 5V 和 3.3V 这两个标准。

电路原理图中的 VCC 或 VDD，代表的是电源正极，GND 代表的是电源的负极。

一般情况下，这种双列直插封装的芯片，左上角是 1 脚，逆时针旋转引脚号依次增加，一直到右上角是最大脚位。

## 2.3 LED 小灯

我们板子上用的是普通的贴片发光二极管。这种二极管通常的正向导通电压是 1.8V 到 2.2V 之间，工作电流一般在 1mA～2mA 之间。其中，当电流在 1mA~5mA 之间变化时， 随着通过 LED 的电流越来越大，我们的肉眼会明显感觉到这个小灯越来越亮，而当电流从 5mA~20mA 之间变化时，我们看到的发光二极管的亮度变化就不是太明显了。当电流超过 20mA 时，LED 就会有烧坏的危险了，电流越大，烧坏的也就越快。所以我们在使用过程中 应该特别注意它在电流参数上的设计要求。

## 2.4 程序代码编写

### 2.4.1 特殊功能寄存器和位定义

第一条语句：`srf P0 = 0x80;`

`sfr`这个关键字是 51 单片机特有的，他的作用是定义一个单片机特殊功能寄存器(special function register)。51 单片机内部有很多个小模块，每个模块居住在拥有唯一房间号的房间内， 同时每个模块都有 8 个控制开关。P0 就是一个功能模块，就住在了 0x80 这个房间里，我们 就是通过设置 P0 内部这个模块的 8 个开关，来让单片机的 P0 这 8 个 IO 口输出高电平或者 低电平的。51 单片机内部有很多寄存器，如果我们想使用的话必须提前进行 sfr 声明。不过 Keil 软件已经把所有这些声明都预先写好并保存到一个专门的文件中去了，我们要用的话只要文件开头添加一行`#include<reg52.h>`即可。

第二条语句：`sbit LED = P0^0;`

这个 sbit，就是对刚才所说的 SFR 中的 8 个开关其中的一个进行定义。这条语句声明了 LED 代表 P0.0 口。

### 2.4.2 新建一个工程

用 Keil 新建一个工程后，会弹出一个对话框让我们选择单片机的型号。因为 Keil 软件并没有收录宏晶 STC89C52，可以选择 Intel 公司名下的 80/87C52 来代替，这个选项对于后边的编程没有任何的不良影响。

Keil 新创建文件后，也需要右键 Source Group，点 Add Files to Group 来把新建的文件添加到目标。

```C
// 点亮 LED 小灯程序
#include <reg52.h>
sbit LED = P0^0;
sbit ADDR0 = P1^0;
sbit ADDR1 = P1^1;
sbit ADDR2 = P1^2;
sbit ADDR3 = P1^3;
sbit ENLED = P1^4;
void main()
//包含特殊功能寄存器定义的头文件 //位地址声明，注意:sbit必须小写、P大写!
{
    ENLED = 0;
    ADDR3 = 1;
    ADDR2 = 1;
    ADDR1 = 1;
    ADDR0 = 0;
    LED = 0;
    while (1);
    //点亮小灯 
    //程序停止在这里
}
```

编译程序前，需要先勾选 Project-->Options for Target 'Target1' 中的 Create HEX File 复选框。设置好以后呢，点击“Project-->rebuild all target files”，或者鼠标点击图 2-19 中红框内的
快捷图标，就可以对程序进行编译了。

下载软件列出了 5 个步骤:第一步，选择单片机型号，我们现在用的单片机型号是 STC89C52RC，这个一定不能选错了;第二步，点击“打开程序文件”，找到我们刚才建立工 程的那个 lesson2 文件夹，找到 LED.hex 这个文件，点击打开;第三步，选择刚才查到的 COM 口，波特率使用默认的就行;第四步，这里的所有选项都使用默认设置，不要随便更改，有 的选项改错了以后可能会产生麻烦。第五步，因为 STC 单片机要冷启动下载，就是先点下载， 然后再给单片机上电，所以我们先关闭板子上的电源开关，然后点击“Download/下载”按钮， 等待软件提示你请上电后，如图 2-23 所示，然后再按下板子的电源开关，就可以将程序下载到单片机里边了。当软件显示“已加密”就表示程序下载成功了
