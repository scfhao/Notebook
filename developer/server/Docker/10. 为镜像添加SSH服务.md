## 基于commit命令创建

Docker提供了`docker commit`命令，支持用户提交自己对制定容器的修改，并生成新的镜像。命令格式为`docker commit CONTAINER [REPOSITORY[:TAG]]`。

用docker commit命令为ubuntu:18.04镜像添加SSH服务：

```Bash
docker pull ubuntu:18.04
docker run -it ubuntu:18.04 bash
root@fc1936ea8ceb:/# apt-get update
root@fc1936ea8ceb:/# apt-get install openssh-server
root@fc1936ea8ceb:/# mkdir -p /var/run/sshd
root@fc1936ea8ceb:/# /usr/sbin/sshd -D &
# 取消pam登录限制：
root@fc1936ea8ceb:/# sed -ri 's/session required pam_loginuid.so/#session required pam_loginuid.so/g' /etc/pam.d/sshd
root@fc1936ea8ceb:/# mkdir root/.ssh
# 把用户的ssh key放到这个文件中
root@fc1936ea8ceb:/# vi /root/.ssh/authorized_keys
# 创建自动启动SSH服务的脚本
# #! /bin/bash
# /usr/sbin/sshd -D
root@fc1936ea8ceb:/# vi /run.sh
root@fc1936ea8ceb:/# chmod +x run.sh
root@fc1936ea8ceb:/# exit
docker commit fc1 sshd:ubuntu
# 使用镜像
docker run -p 10022:22 -d sshd:ubuntu /run.sh
ssh 192.168.1.200 -p 10022
```

## 使用Dockerfile创建

```Bash
mkdir sshd_ubuntu
cd sshd_ubuntu
touch Dockerfile run.sh
cat ~/.ssh/id_rsa.pub > authorized_keys
```

run.sh

```Bash
#! /bin/bash
/usr/sbin/sshd -D
```

Dockerfile

```Dockerfile
# 设置继承镜像
FROM ubuntu:18.04
# 提供一些作者的信息
MAINTAINER docker_user (user@docker.com)
# 下面开始运行命令
RUN apt-get update
RUN apt-get install -y openssh-server
RUN mkdir -p /var/run/sshd
RUN mkdir -p /root/.ssh
RUN sed -ri 's/session required pam_loginuid.so/#session required pam_loginuid.so/g' /etc/pam.d/sshd
ADD authorized_keys /root/.ssh/authorized_keys
ADD run.sh /run.sh
RUN chmod 755 /run.sh
#开放端口
EXPOSE 22
#设置启动命令
CMD ["/run.sh"]
```

```Bash
cd sshd_ubuntu
docker build -t sshd:dockerfile .
docker run -d -p 10122:22 sshd:dockerfile
ssh 192.168.1.200 -p 10122
```
