# [为什么不建议使用 mac 上自带的 ruby 来安装 gems](https://www.moncefbelyamani.com/why-you-shouldn-t-use-the-system-ruby-to-install-gems-on-a-mac/)

自带 Ruby 版本比较旧，一般自带 2.x，而最新的 ruby 版本是 3.x。系统自带的 ruby 存在的原因是为了兼容历史软件。苹果后期也会逐渐移出这些自带的脚本。

## 建议的安装方式

使用 Ruby 版本管理工具安装更新的 Ruby。Ruby 版本工具可以让你同时安装多个版本的 Ruby，并在他们之间切换。

虽然用 Homebrew 可以直接安装 Ruby，但是这种方式同时只能使用一个版本。

版本管理工具推荐使用`chruby`和`ruby-install`。

使用这两个工具配置合适的 Ruby 环境时有两个选项：

* 只需一个命令，即可在 15 分钟或更短时间内为您设置好一切(购买[Ruby on Mac](https://www.rubyonmac.dev/#features))
* 花费 60 分钟或更多时间手动设置一切，[手动安装教程](https://www.moncefbelyamani.com/how-to-install-xcode-homebrew-git-rvm-ruby-on-mac/#start-here-if-you-choose-the-long-and-manual-route)

## 准备

1. 如果已安装 Homebrew，且用 Homebrew 安装了 Ruby或Cocoapods，先卸载(清理与其相关的环境变量)：

```
brew uninstall ruby
```

2. 确定没有安装其他 ruby 工具：rvm、rbenv、asdf、frum

## 安装

### M 芯片需注意

确保终端不是以`Rosetta`模式运行的。用下面命令检查：

```
uname -m
# 输出 arm64 即正常模式
```

### 步骤一：安装 Homebrew

略

### 步骤二：使用 ruby-install 安装 chruby 和最新的 Ruby

```
# 安装 chruby 和 ruby-install
brew install chruby ruby-install
# 安装最新版 ruby
ruby-install ruby
# 配置环境变量
echo "source $(brew --prefix)/opt/chruby/share/chruby/chruby.sh" >> ~/.zshrc
echo "source $(brew --prefix)/opt/chruby/share/chruby/auto.sh" >> ~/.zshrc
echo "chruby ruby-3.3.1" >> ~/.zshrc
```

### 步骤三：安装一个 gem

确保不要使用`sudo`安装任何 gems！

## 安装不同版本的 Ruby 并切换

如果你的命令行工具或Xcode版本高于14，并且要安装 Ruby 2.77～3.1.3

```
ruby-install 3.1.2 -- --enable-shared
```

否则：

```
ruby-install 3.1.2
```

要切换到新安装的 Ruby 版本：

```
chruby ruby-3.1.5
```

## 推荐的自动切换到正确版本的方式

在某个文件夹下创建 ruby-version 文件，这样可以配置这个文件夹中的 ruby 版本。

```
echo '3.2.4' >> .ruby-version
```

这样做的前提是已经安装了 Ruby 3.2.4。可以运行`chruby`检查安装了哪些版本。

在包含`Gemfile`的项目中，在`Gemfile`中指定 ruby 版本也是个好办法，但要和同目录下的`.ruby-version`中指定的版本一致，可以在`Gemfile`中第一个 Gem 前面用这段代码从`.ruby-version`中读取版本号：

```
ruby File.read(".ruby-version").strip
```

示例：

```
source "https://rubygems.org"
git_source(:github) { |repo| "https://github.com/#{repo}.git" }

ruby File.read(".ruby-version").strip

gem "rails", "~> 7.0.4"
```
