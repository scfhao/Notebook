# 在 macOS 上配置 Postfix

http://www.developerfiles.com/how-to-send-emails-from-localhost-mac-os-x-el-capitan/

Postfix 是 macOS 上默认安装的标准邮件服务。

## 步骤 1，编辑 Postfix 配置文件

先检查 Postfix 是否正确配置了下面几行（他们可能是分开的）：

```bash
$ sudo vi /etc/postfix/main.cf
```

```
mydomain_fallback = localhost
mail_owner = _postfix
setgid_group = _postdrop
```

然后在这个文件的最下方增加下面几行：

```
#Gmail STMP
relayhost=smtp.gmail.com:587
# Enable SASL authentication in the Postfix SMTP client.
smtp_sasl_auth_enable=yes
smtp_sasl_password_maps=hash:/etc/postfix/sasl_passwd
smtp_sasl_security_options=noanonymous
smtp_sasl_mechanism_filter=plain
# Enable Transport Layer Security (TLS), i.e. SSL.
smtp_use_tls=yes
smtp_tls_security_level=encrypt
tls_random_source=dev:/dev/urandom
```

这会告诉 Postfix 使用 Gmail SMTP 服务器的 Simple Authentication and Security Layer(SASL). 将保存于'/etc/postfix/sasl_passwd'。当然可以用其他的邮件服务器，只需要改 relayhost 就行了。

## 步骤2. 创建 sasl_passwd 文件

```bash
$ sudo vi /etc/postfix/sasl_passwd
```

输入如下的内容并保存：

```
smtp.gmail.com:587 your_email@gmail.com:your_password
```

创建 sasl_passwd 的 Postfix 查找表

```bash
$ sudo postmap /etc/postfix/sasl_passwd
// 这会创建 sasl_passwd.db
```

## 步骤3. 启动或重启 Postfix

```bash
# 下面两条命了根据自身情况选一条执行就行
$ sudo postfix start
$ sudo postfix reload
```

## 步骤4. 开启 less secure apps

Gmail 专有，设置[less secure apps](https://myaccount.google.com/lesssecureapps?pli=1)，不开启会报错`SASL authentication failed`

## 步骤5. 测试

测试向自己的邮箱发送一封邮件

```bash
$ date | mail -s testing your_email@gmail.com
```

检查邮件队列和可能的发送错误

```bash
$ mailq
```

使用 postfix 日志来确保一切正常

```bash
$ tail -f /var/log/mail.log
```

## 其他有用的命令

清除邮件队列

```bash
$ sudo postsuper -d ALL
```
