macOS 的 IP 转发功能可以转发其他主机的数据流量，让其他主机拥有本机的上网环境。已知的使用场景有：

1. A、B 两台电脑在同一个局域网中，其中 A 有上网权限，而 B 会被路由器拒绝，那B可以通过A提供的 IP 转发突破网络限制。
2. 为 Apple Container（2026） 中的容器提供互联网访问权限（可能 Apple Container 后续版本会提供类似于 Docker 的自动配置功能，到时候就不需要再配置 IP 转发了）

IP 转发需要配置两个地方，一是打开 IP 转发的开关，二是配置防火墙

## IP 转发开关

```bash
sudo sysctl -w net.inet.ip.forwarding=1
```

如果希望永久生效，需要将`net.inet.ip.forwarding=1`写入`/etc/sysctl.conf`。

## 防火墙

```bash
echo "nat on en0 from 192.168.64.0/24 to any -> (en0)" | sudo pfctl -ef -
```

如果希望永久生效，并将 NAT 规则写入`/etc/pf.conf`文件中。

> 注意这里的网络接口 en0，如果宿主机的网络是 USB 网络共享，可以通过`ifconfig | grep -A 2 "inet 172.20.10"`获取对应的网络接口。
