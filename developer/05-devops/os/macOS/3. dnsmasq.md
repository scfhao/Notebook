1. 安装

```Bash
brew install dnsmasq
```

2. 修改配置文件

`/opt/homebrew/etc/dnsmasq.conf`

```
# 指定上游 DNS 服务器（如 Google DNS）
server=8.8.8.8
server=8.8.4.4

# 禁用本机 hosts 文件（可选）
no-hosts

# 监听本地地址（127.0.0.1）
listen-address=127.0.0.1

# 自定义域名解析（如将 example.com 指向 192.168.1.100）
address=/example.com/192.168.1.100
```

3. 启动

```Bash
brew services start dnsmasq
```

4. 系统设置 DNS 地址为`127.0.0.1`

5. 刷新 DNS 缓存

```Bash
sudo killall -HUP mDNSResponder
```

6. 测试

```Bash
dig example.com @127.0.0.1
```
