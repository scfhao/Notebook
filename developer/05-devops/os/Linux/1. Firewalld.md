Firewalld 使用两个单独的配置集，即运行时配置和永久配置。

运行时配置是实际的运行配置，并且不会再重新启动后持续存在，当 firewalld 守护程序启动时，它将加载永久配置，该配置将成为运行时配置。

默认情况下，使用 firewall-cmd 实用程序对 Firewalld 配置进行更改时，更改将应用于运行时配置，要使更改永久生效，请在命令后附加`--permanent`选项。

要在两个配置集中应用更改，可以使用一下两种方法之一：

1. 更改运行时配置并将其永久化：

```Bash
$ sudo firewall-cmd <options>
$ sudo firewall-cmd --runtime-to-permanent
```

2. 更改永久配置并重新加载 firewalld 守护程序：

```Bash
$ sudo firewall-cmd --permanent <options>
$ sudo firewall-cmd --reload
```

```Bash
$ sudo dnf install firewalld
$ sudo systemctl enable firewald --now
```

检查防火墙状态：

```Bash
$ sudo firewall-cmd --state
```

## 防火墙区域

默认区域设置为 public。可以通过键入以下命令查看默认区域：

```Bash
$ sudo firewall-cmd --get-default-zone
```

要获取所有可用区域的列表，可以：

```Bash
$ sudo firewall-cmd --get-zones
```

要查看活动区域和分配给它们的网络接口，请执行以下操作：

```Bash
$ sudo firewall-cmd --get-active-zones
```

可以使用以下命令打印区域配置设置：

```Bash
$ sudo firewall-cmd --zone=public --list-all
```

## 防火墙服务

使用防火墙，可以基于称为服务的预定义规则允许特定端口或源的流量。

要获取所有默认可用服务的列表，请输入：

```Bash
$ sudo firewall-cmd --get-services
```

可以打开`/usr/lib/firewalld/services/`目录中的关联`xml`文件，找到有关每个服务的更多信息。

要仅将对运行时配置允许公共区域中的接口允许传入的 HTTP 通信(80端口)，请输入：

```Bash
$ sudo firewall-cmd --zone=public --add-service=http
```

要验证是否已经成功添加服务，请使用`--list-services`选项：

```Bash
$ sudo firewall-cmd --zone=public --list-services
```

删除服务的语法与添加服务时的语法相同，只需使用`--remove-service`而不是`--add-service`选项即可：

```Bash
$ sudo firewall-cmd --zone=public --remove-service=http --permanent
```

创建一个新服务，创建新服务的最简单方法是将现有服务文件复制到`/etc/firewalld/services`目录(该目录是用户创建的服务的位置)，并修改文件内容。

## 打开/关闭源或端口

```Bash
$ sudo firewall-cmd --zone=public --add-source=192.168.1.10
$ sudo firewall-cmd --zone=public --list-sources
$ sudo firewall-cmd --zone=public --remove-source=192.168.1.10

$ sudo firewall-cmd --zone=public --add-port=8080/tcp
# 可选协议为tcp/udp/sctp/dccp
$ sudo firewall-cmd --zone=public --list-ports
$ sudo firewall-cmd --zone=public --remove-port=8080/tcp
```

## 转发端口

要将流量从一个端口转发到另一个端口，请使用`--add-masquerade`选项启用对所需区域的伪装，例如，要对外部区域启用伪装，请键入：

```Bash
$ sudo firewall-cmd --zone=external --add-masquerade
```

1. 将流量从一个端口转发到 IP 地址上的另一个端口

```Bash
$ sudo firewall-cmd --zone=external --add-forward-port=port=80:proto=tcp:toport=8080
```

2. 将流量转发到另一个 IP 地址

```Bash
$ sudo firewall-cmd --zone=external --add-forward-port=port=80:proto=tcp:toaddr=10.10.10.2
```

3. 将流量转发到其他端口上的另一台服务器

```Bash
$ sudo firewall-cmd --zone=external --add-forward-port=port=80:proto=tcp:toport=8080:toaddr=10.10.10.2
```
