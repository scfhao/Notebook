1. 使任务在后台执行：命令 &
例：`git clone https://github.com/name/repo.git &`

2. 暂停并把任务放到后台 ctrl z

3. 查看所有后台任务状态`jobs -l`

4. 将后台任务切换到前台`fg %jobnumber`，bg就是放后台，jobnumber是一个从1开始的数字。

5. 关掉一个任务：`kill -signal %jobnumber`，signal可以是9，每个数字有不同含义。

6. 查看当前的环境变量：env

7. 设置变量`variable=value`和取消`unset variable`(这两个命令中变量前不需要有$)

8. 有些变量的值可能来源于一些命令，这时你可以使用反单引号`命令`或$(命令).

9. 环境变量配置文件：`/etc/profile`和`~/.bash_profile`。

10. 重定向

stdin，表示标准输入，代码为0，使用`<`(表示以文件内容作为输入)或`<<`(表示输入时的结束符号)操作符。
stdout，表示标准输出，代码为1，使用`>`(表示以覆盖的方式将正确的数据输出到指定文件中)或`>>`(表示以追加的方式将正确的数据输出到指定文件中)操作符。
stderr，表示标准错误输出，代码为2，使用`2>`(表示以覆盖的方式将错误输出到指定文件中)或`2>>`(表示以追加的方式将错误的数据输错到指定的文件中)操作符号

stdout和stderr两个输出可以同时存在，也可以合并，如果想将正确输出数据和错误输出数据合并输出到同一个文件，可以使用`&>`符号。

`<<`符号，这个符号可以定义结束标志，例如输入`cat > test << "abc"`命令后，你可以输入一些文字，最后输入abc再点回车时，可以结束输入。
