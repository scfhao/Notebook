## 手动拉取镜像并导入 Minikube

1. 在宿主机（本地 Docker）拉取镜像

```shell
docker pull registry.cn-hangzhou.aliyuncs.com/google_containers/kicbase:v0.0.47
```

2. 重新打标签

如果镜像名称与`minikube`预期的不一致（如阿里云镜像路径不同），需修改标签：

```shell
docker tag registry.cn-hangzhou.aliyuncs.com/google_containers/kicbase:v0.0.47 kicbase/stable:v0.0.47
```

3. 导入到 Minikube 缓存

将镜像加载到`minikube`的本地缓存，避免重复拉取：

minikube cache" will be deprecated in upcoming versions, please switch to "minikube image load

```shell
minikube cache add kicbase/stable:v0.0.47
```

或直接导入：

```shell
minikube image load kicbase/stable:v0.0.47
```

4. 启动 Minikube 并指定镜像

使用`--base-image`参数指定已拉取的镜像：

```shell
minikube start --base-image=kicbase/stable:v0.0.47
minikube start --base-image=kicbase/stable:v0.0.47 --image-repository=registry.cn-hangzhou.aliyuncs.com/google_containers --cpus=4 --memory=4096mb
```
