1. 安装

```bash
brew install container
```

2. 初始化（下载内核与运行时工具）

```bash
container system start
```

3. 把 docker 中的镜像导出到 container：

```bash
docker save -o rockylinux.tar rockylinux:8.9

container image load -i rockylinux.tar

# 或者一步到位

docker save myapp:latest | container image load
```

4. 查看本地镜像

```bash
container image list
```

5. 启动镜像

```bash
container run -dit \
  --name my-rocky \
  -v $(pwd)/data:/data \
  rockylinux:8.9
```

* `-d, --detach`: 让容器在后台运行，释放当前终端，`-it`选项也必不可少，不然容器启动后会立刻退出

> 和 Docker 不同的是，container 会为每个容器分配一个独立的 IP 地址，宿主机可以通过 IP 或 DNS 的方式直接访问容器的网络，所以可以不配置端口转发。

列出容器：

```bash
container list --all
```

6. 进入后台容器

```bash
container exec -it my-rocky /bin/bash
```

7. 停止容器

```bash
container stop my-rocky
# 停止全部 --all
container stop -a
```

8. 启动容器

```bash
container start my-rocky
```

9. 网络环境配置

当前版本的 Apple Container 不会自动为容器配置 NAT，所以如果容器需要访问网络的话，需要手动配置，参考[IP 转发](../../../05-devops/os/macOS/4.%20IP转发.md)
