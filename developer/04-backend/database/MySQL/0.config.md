## 安全

MySQL 提供了一个试用方便的命令`sudo mysql_secure_installation`，这个命令对于加强安装的 MySQL 的安全大有帮助。其功能如下：

* 更新密码插件
* 为 root 帐户设置密码
* 删除可以从本地主机外访问的根帐户
* 删除匿名用户帐户
* 删除测试数据库和允许任何人访问名称以 test_ 开头的数据库的权限
