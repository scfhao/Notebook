## 1.3 创建一个数据库

```Bash
createdb mydb
# 如果不指明数据库名，数据库名同用户名
createdb
```

删除数据库:

```Bash
dropdb mydb
```

## 1.4 访问数据库

可以通过以下方式访问：

* 运行PostgreSQL的交互式终端程序，它被称为psql，它允许你交互地输入、编辑和执行SQL命令。
* 使用一种已有的图形化前端工具，比如pgAdmin或者带ODBC或JDBC支持的办公套件来创建和管理数据库。这种方法在这份教程中没有介绍。
* 使用多种绑定发型的语言中的一种写一个自定义的应用。这些可能在第四部分中将有更深入的讨论。

```Bash
psql mydb
```

psql程序有一些不属于SQL命令的内部命令。它们以反斜线开头。

```Bash
# 你可以用下面的命令获取各种PostgreSQL的SQL命令的帮助语法
\h
# 退出psql
\q
# 要获取更多有关内部命令的信息，你可以在psql提示符上键入\?
\?
```
