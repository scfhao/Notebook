1. 加密解密

```SQL
-- 数据，密码，算法，加解密需要插件 pgcrypto
encrypt('18634336001', 'sgas', 'aes');
decript('data', 'sgas', 'aes');
```

2. 编解码

```SQL
encode('data', 'base64');
decode('79T1k6xB4W3+yptVEzq3Gg==', 'base64');
```

3. 字符编解码

```SQL
convert_to('abc text', 'UTF-8');
convert_from('data', 'UTF-8');
```

总结：

```SQL
select encode(encrypt('18634336001', 'sgas', 'aes'), 'base64');
select CONVERT_FROM(decrypt(decode('79T1k6xB4W3+yptVEzq3Gg==', 'base64'), 'sgas', 'aes'), 'UTF-8');
```
