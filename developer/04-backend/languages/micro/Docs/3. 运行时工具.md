```Bash
// 安装 micro
go get -u github.com/micro/micro
```

Micro内置了mDNS组播系统，这是一种零依赖的服务注册发现机制，它是区别于有注册中心的替代方案。

通过在启动指令中传入--registry=mdns 或者在环境变量中设置MICRO_REGISTRY=mdns。

其实也可以不传，早期版本的go-micro默认注册中心是consul，现在换成了mdns

```
# 使用命令行参数
micro --registry=mdns list services

micro --registry=etcd --registry_address=10.185.102.238:2379,10.185.102.239:2379,10.185.102.240:2379 list services

# 使用环境变量
MICRO_REGISTRY=etcd \
MICRO_REGISTRY_ADDRESS=10.185.102.238:2379,10.185.102.239:2379,10.185.102.240:2379 \
micro list services
```
MICRO_REGISTRY=etcd \
MICRO_REGISTRY_ADDRESS=10.185.102.238:2379,10.185.102.239:2379,10.185.102.240:2379 \
micro call com.foxconn.micro.srv.snowflake Snowflake.GenID 


MICRO_REGISTRY=etcd \
MICRO_REGISTRY_ADDRESS=10.185.102.238:2379,10.185.102.239:2379,10.185.102.240:2379 \
micro web

MICRO_REGISTRY=etcd \
MICRO_REGISTRY_ADDRESS=10.185.102.238:2379,10.185.102.239:2379,10.185.102.240:2379 \
