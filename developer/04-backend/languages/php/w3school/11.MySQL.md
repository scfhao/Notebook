## 连接

在能够访问并处理数据库中的数据之前，必须创建到达数据库的连接。

在PHP中，这个任务通过 mysql_connect()函数完成。

mysql_connect(servername,username,password);

参数 | 描述
----|-----
servername | 可选。规定要连接的服务器。默认是"localhost:3306"
username | 可选。规定登录所使用的用户名。默认值是拥有服务器进行的用户的名称。
password | 可选。规定登录所使用的密码。默认是""。

其他参数参考PHP MySQL手册。

脚本一结束，就会关闭连接。如需提前关闭连接，请使用 mysql_close()函数。

```
<?php
$con = mysql_connect("localhost","peter","abc123");
if (!$con)
{
	die('Could not connect: ' . mysql_error());
}
mysql_close($con);
?>
```

## 创建

mysql_query()函数用于向MySQL连接发送查询或命令。

例：创建数据库

```
mysql_query("CREATE DATABASE my_db", $con)
```

例：创建Persons表，有三列，FirstName，LastName，Age。

```
mysql_select_db("my_db", $con);
$sql = "CREATE TABLE Persons
(
	FirstName varchar(15),
	LastName varchar(15),
	Age int
)"
mysql_query($sql,$con);
```

> 在创建表之前，必须首先选择数据库。通过mysql_select_db()函数选取数据库。当创建varchar类型的数据库字段时，必须规定该字段的最大长度，例如：varchar(15)。

## MySQL 数据类型

数据类型 | 描述
--------|-----
int(size) smallint(size) tinyint(size) mediumint(size) bigint(size) | 仅支持整型。在size参数中规定数字的最大值。
decimal(size,d) double(size,d) float(size,d) | 支持带有小数的数字。在size参数中规定数字的最大值。在d参数中规定小数点右侧的数字的最大值。

文本数据类型 | 描述
-----------|------
char(size) | 支持固定长度的字符串。（可包含字母、数字以及特殊符号）。在size参数中规定固定长度。
varchar(size) | 支持可变长度的字符串。（可包含字母、数字以及特殊符号）。在size参数中规定最大长度。
tinytext | 支持可变长度的字符串，最大长度是255个字符。
text blob | 支持可变长度的字符串，最大长度是65535个字符。
mediumtext mediumblob | 支持可变长度的字符串，最大长度是16777215个字符。
longtext longblob | 支持可变长度的字符串，最大长度是4294967295个字符。

日期数据类型 | 描述
-----------|------
date(yyyy-mm-dd) datetime(yyyy-mm-dd hh:mm:ss) timestamp(yyyymmddhhmmss) time(hh:mm:ss) | 支持日起或时间

杂项数据类型 | 描述
-----------|-----
enum(value1,value2,ect) | ENUM是ENUMERATED列表的缩写。可以在括号中存放最多65535个值。
set | SET与ENUM相似。但是，SET可拥有最多64个列表项目，并可存放不止一个choice

## 主键与自动递增字段

主键字段永远要被编入索引。这条规则没有例外。例：

```
$sql = "CREATE TABLE Persons
(
personID int NOT NULL AUTO_INCREMENT,
PRIMARY KEY(personID),
FirstName varchar(15),
LastName varchar(15),
Age int
)"
```

## 插入

INSERT INTO 语句用于向数据库表添加新记录。

语法：

INSERT INTO table_name VALUES (value1, value2,...)

或者指定希望插入数据的列：

INSERT INTO table_name (column1, column2,...) VALUES (value1, value2,...)

## 查找

```
$result = mysql_query("SELECT * FROM Persons")
while ($row = mysql_fetch_array($result))
{
    echo $row(['FirstName'] . " " . $row['LastName'];
    echo "<br />";
}
```

上面这个例子在$result变量中存放由mysql_query()函数返回的数据。接下来，我们使用mysql_fetch_array()函数以数组的形式从记录集返回第一行。每个随后对mysql_fetch_array()函数的调用都会返回记录集中的下一行。while循环语句会循环记录集中的所有记录。

可以与WHERE子句一起使用的运算符：

运算符 | 说明
------|------
= | 等于
!= | 不等于
> | 大于
< | 小于
>= | 大于或等于
<= | 小于或等于
BETWEEN | 介于一个包含范围内
LIKE | 搜索匹配的模式

ORDER BY 关键词用于对记录集中的数据进行排序。记录集的排序顺序默认是升序，使用DESC关键字来设定降序排序。

可以根据多个列进行排序，当按照多个列进行排序时，只有第一列相同时才使用第二列。

UPDATE语句用于在数据库表中修改数据。

UPDATE table_name SET column_name = new_value WHERE column_name = some_value

DELETE FROM语句用于从数据库表中删除记录。

DELETE FROM table_name WHERE column_name = some_value
