[GitHub](https://github.com/nvm-sh/nvm)

`nvm`允许你通过命令行快速安装和使用不同版本的 node。

```bash
$ nvm install 24
Now using node v24.14.0 (npm v11.9.0)
$ node -v
v24.14.0
$ nvm use 22
Now using node v22.22.1 (npm v10.9.4)
$ node -v
v22.22.1
$ nvm use 20
Now using node v20.20.1 (npm v10.8.2)
$ node -v
v20.20.1
```

1. 安装nvm

要安装或更新 nvm，你需要运行安装脚本。为此，你可以手动下载并运行该脚本，也可以使用以下 cURL 或 Wget 命令：

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash

wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
```

2. 老版本 node 安装

在 m 系列 Mac 上，编译老版本 node 存在兼容性问题，需借助 Rosetta2 来安装：

```bash
softwareupdate --install-rosetta
arch -x86_64 zsh
nvm install 14
```
