```swift
import Fluent

final class Galaxy: Model {
    // 表或集合名。
    static let schema = "galaxies"

    // 星系唯一标识符。
    @ID(key: .id)
    var id: UUID?

    // 星系名称。
    @Field(key: "name")
    var name: String

    // 创建一个空的星系。
    init() { }

    // 创建一个新的星系并设置所有属性。
    init(id: UUID? = nil, name: String) {
        self.id = id
        self.name = name
    }
}
```

> 建议将模型类标记为`final`，以提高性能并简化一致性要求。

`Model`协议第一个要求是静态字符串`schema`。

此属性告诉 Fluent 模型对应于哪个表或集合。这可以是数据库中已经存在的表，也可以是你将通过 migration 创建的表。schema 通常是`snake_case`复数形式.

下一个要求是一个名为`id`的标识符字段。

该字段必须使用`@ID`属性包装器。Fluent 建议使用`UUID`和特殊`.id`字段键，因为它兼容 Fluent 的所有驱动程序。

如果要使用自定义 ID 键或类型， 请使用`@ID(custom:)`重载。

所有模型都需要一个空的 init。
