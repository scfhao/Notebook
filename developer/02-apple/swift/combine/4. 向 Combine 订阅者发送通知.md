# 向 Combine 订阅者发送通知

使用通知中心的发布者向订阅者发送通知。

## 概述

许多框架通过 NotificationCenter API 将异步事件传递给您的应用。您的应用可能已在回调方法或闭包中设置了接收和处理这些通知。例如，以下代码使用`addObserver(forName:object:queue:using:)`方法，在 iOS 设备每次旋转至纵向模式时打印一条消息。

```swift
var notificationToken: NSObjectProtocol?
override func viewDidLoad() {
    super.viewDidLoad()
    notificationToken = NotificationCenter.default
        .addObserver(forName: UIDevice.orientationDidChangeNotification,
                     object: nil,
                     queue: nil) { _ in
                        if UIDevice.current.orientation == .portrait {
                            print ("Orientation changed to portrait.")
                        }
    }
}
```

## 将通知处理代码迁移至 Combine

使用通知中心回调和闭包时，所有操作都必须在回调方法或闭包内部完成。迁移至Combine后，可通过运算符实现过滤等常见任务。

要充分利用 Combine，请使用`NotificationCenter.Publisher`将`NSNotification`处理代码迁移至 Combine 范式。通过 NotificationCenter 的`publisher(for:object:)`方法创建发布者，传入您关注的通知名称及源对象（如有）。

请参照下列代码示例，将上述逻辑重写为 Combine 风格。该代码通过默认通知中心创建`orientationDidChangeNotification`通知的发布者。当代码接收来自该发布者的通知时，会应用过滤运算符仅处理纵向模式通知，并输出相应消息。

```swift
var cancellable: Cancellable?
override func viewDidLoad() {
    super.viewDidLoad()
    cancellable = NotificationCenter.default
        .publisher(for: UIDevice.orientationDidChangeNotification)
        .filter() { _ in UIDevice.current.orientation == .portrait }
        .sink() { _ in print ("Orientation changed to portrait.") }
}
```

请注意，在此情况下，`orientationDidChangeNotification`的`userInfo`字典中并不包含新的方向信息，因此`filter(_:)`操作符会直接查询`UIDevice`。
