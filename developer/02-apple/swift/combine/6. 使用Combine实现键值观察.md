# 使用Combine实现键值观察

通过Combine发布者暴露KVO变更。

## 概述

若干框架采用键值观察机制，用于向应用程序通知异步变更。通过将键值观察（KVO）的使用方式从回调和闭包转换为 Combine，可使代码更具优雅性与可维护性。

## 使用 KVO 监测变化

在下面的示例中，UserInfo 类型为其`lastLogin`属性支持 KVO，具体实现方式详见[在Swift中使用键值观察](https://developer.apple.com/documentation/swift/using-key-value-observing-in-swift)。`viewDidLoad()`方法通过`observe(_:options:changeHandler:)`方法设置闭包来处理该属性的任何变更。该闭包接收描述变更事件的`NSKeyValueObservedChange`对象，获取`newValue`属性并将其打印出来。`viewDidAppear(_:)`方法修改该值时，会调用闭包并输出提示信息。

```swift
class UserInfo: NSObject {
    @objc dynamic var lastLogin: Date = Date(timeIntervalSince1970: 0)
}
@objc var userInfo = UserInfo()
var observation: NSKeyValueObservation?

override func viewDidLoad() {
    super.viewDidLoad()
    observation = observe(\.userInfo.lastLogin, options: [.new]) { object, change in
        print ("lastLogin now \(change.newValue!).")
    }
}

override func viewDidAppear(_ animated: Bool) {
    super.viewDidAppear(animated)
    userInfo.lastLogin = Date()
}
```

## 转换 KVO 代码为使用 Combine

要将KVO代码转换为 Combine，请用`NSObject.KeyValueObservingPublisher`替换`observe(_:options:changeHandler:)`方法。通过在父对象上调用`publisher(for:)`即可获取该发布器的实例，如下例viewDidLoad()方法所示：

```swift 
class UserInfo: NSObject {
    @objc dynamic var lastLogin: Date = Date(timeIntervalSince1970: 0)
}
@objc var userInfo = UserInfo()
var cancellable: Cancellable?

override func viewDidLoad() {
    super.viewDidLoad()
    cancellable = userInfo.publisher(for: \.lastLogin)
        .sink() { date in print ("lastLogin now \(date).") }
}

override func viewDidAppear(_ animated: Bool) {
    super.viewDidAppear(animated)
    userInfo.lastLogin = Date()
}
```

KVO 发布者会生成被观察类型的元素——本例中为`Date`类型——而非`NSKeyValueObservedChange`对象。这省去了一个步骤，因为您无需像第一个示例那样从变更对象中解包`newValue`。
