# Theos

Theos 是一个越狱开发工具包，由 Dustin Howett 开发。还有一个开发工具叫 iOSOpenDev 是整合在 Xcode 里的。

## 配置

1. Theos 下载。GitHub:DHowett/theos，例如下载到/opt/theos/
```
sudo git clone --recursive https://github.com/theos/theos.git /opt/theos
```

2. ldid下载。ldid 是专门用来签名 iOS 可执行文件的工具，用以在越狱 iOS 中取代 Xcode 自带的 codesign。[下载地址](http:/joedj.net/ldid)，[下载地址2](https://github.com/downloads/rpetrich/ldid/ldid.zip)，例如下载到/opt/theos/bin/下。

3. 下载 CydiaSubstrate。需要先运行`sudo /opt/theos/bin/bootstrap.sh substrate`，会生成`/opt/theos/lib/libsubstrate.dylib`文件，如果这个文件不能用，可以先在 Cydia 中搜索并安装 Cydia Substrate，然后从手机的`/Library/Frameworks/CydiaSubstrate.framework/CydiaSubstrate`复制到目标位置。

4. 配置 dpkg-deb。deb 是越狱开发安装包的标准格式，dpkg-deb 是一个用于操作 deb 文件的工具，有了这个工具，theos 才能正确地把工程打包成 deb 文件。[下载地址](https://githubusercontent.com/DHowett/dm.pl/master/dm.pl)，下载下 dm.pl 后，重命名并放到 `/opt/theos/bin/`。

## 用法

1. 创建工程，/opt/theos/bin/nic.pl

2. 选择模版，例如输入9回车，即选择`[9.] iphoe/tweak`

3. 输入工程名称。

4. 输入 deb 包名（类似于 bundle identifier）

5. 输入 tweak 作者的名字

6. 输入目标应用 Bundle ID

7. 输入 tweak 安装完成后需要重启的应用，以进程名表示。
