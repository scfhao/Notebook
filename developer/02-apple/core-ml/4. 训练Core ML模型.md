Xcode 自带工具 Create ML

创建项目，类型选择 Tabular Regression（表格回归）。

训练流程为：Setting->Training->Evaluation->Preview->Output 五个步骤。

## Setting

需要设置训练数据（Training Data）、验证数据（Validation Data）、测试数据（Testing Data）。

这三个数据都要求是首行为表头的 csv 格式数据。

通常训练数据的数据量最大（教程使用了1万行数据），设置训练数据后，需从训练数据的列中选择目标（Target）和特性（Features），目标和特性都是表数据中的列，模型最终根据特性数据推算出目标列的值（特性含多列，目标为1列）。

默认使用训练数据的一小部分作为验证数据，模型使用验证数据改善预测结果，验证数据最终不会成为模型的一部分。

测试数据用于训练结束后对模型的精度进行评估（教程中使用了1千行数据的文件）。

算法选择可以保持“自动”选项，Create ML 自动选择适合的算法。

## Training

点击运行按钮，训练结束后，会自动跳到下一步。

## Evaluation

测试结果中的“Maximum Error”代表预测数据与测试数据最不准确的情况。鉴于所有训练数据都使用整数，所以这个值小于0.5是很好的。这意味着在1000次试验中，该模型对每一次的风险整数都做出了最接近的预测。

“Root Mean Square Error”代表整个模型的误差。由于它必然低于最大误差，因此你可以确信该模型会根据训练数据预测结果。

好的模型在训练数据并非完全一致时会产生更高的误差。现实世界的数据存在异常值和错误。在这种情况下，评估模型时应问“这个预测有用吗？”而不是“这个预测正确吗？”

## Preview

打开 Preview 选项卡，点击左下角的`+`，添加 TrailExamples.csv。

使用窗格底部的行号控件浏览部分示例。TrailExamples.csv中的每个值都有其自己的行。将模型的预测结果与预先计算的结果进行比较。结果是否在误差值范围内？

## Output

切换到 Output 选项卡，点击 Get 按钮保存我们的模型。我们将在下个教程中使用该模型。

## 了解训练算法

在导航窗格中，按住Control键并点击模型名称，将其重命名为TrailAnalyzer Automatic。然后再次按住Control键并点击该模型，选择“复制”，并将新复制的模型重命名为“决策树”。复制的模型会继承已训练模型的设置，因此可以对其进行修改和重新训练。

在“设置”选项卡中，参数下方，打开“算法”菜单并选择“决策树”。树形数据结构由一系列仅有一个父节点的节点组成——你可以将决策树视为机器学习流程图。

决策树算法在只有少数输出的情况下效果最佳。

点击左上角的“训练”。训练完成后，在评估标签页中查看错误。决策树模型的表现明显不如自动模型。遗憾的是，这种算法并不适合用于轨迹数据。为问题选择正确的方法，与以最佳方式执行该方法同样重要。

梯度提升树和随机森林算法以更复杂的方式使用决策树。虽然它们可以在决策树的基础上进行改进，但无法解决决策树本身不能解决的问题。

线性回归模型通过将每个输入乘以一个权重后相加来进行预测。该试验模型对四个输入值分别赋予了不同的权重。

Create ML中的自动训练会从可用算法中进行选择。现在你可以看到，它可能选择了线性回归。
