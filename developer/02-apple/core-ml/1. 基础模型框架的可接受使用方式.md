# 基础模型框架的可接受使用要求

这些要求适用于希望使用、提示或公开基础模型框架的开发者。

## 禁止用途

你不得以下列方式使用、提示或披露基础模型框架（包括该框架所访问的模型），也不得鼓励或允许他人这样做：

* 违反法律、法规或其他法律要求；
* 以任何理由宣扬或助长暴力；
* 生成具有诽谤性或恶意的内容；
* 生成包含、呈现或以其他方式涉及色情内容或公然性材料的内容；
* 促进或助长儿童性剥削或虐待；
* 宣扬或促成自残；
* 从事任何形式的欺诈、欺骗或侵权活动；
* 从事受监管的医疗、法律或金融服务；
* 从事与就业相关的服务、对个人实施刑事犯罪的风险进行评估，或供与执法或刑事司法相关的官方使用；
* 从事社会评分或预测性民意调查；
* 根据生物识别数据对个人进行分类，以推断敏感属性；
* 试图破坏或未经授权访问第三方的网络或系统；
* 鼓励非法或鲁莽地使用武器及危险物品；
* 侵犯或违反他人（包括苹果公司）的知识产权、公开权或隐私权；
* 以虚假或贬低的方式展示苹果公司或其产品；
* 规避集成到基础模型框架或配套技术中的任何安全政策、防护措施或限制；
* 生成、逆向工程、总结、翻译或以其他方式重现基础模型框架的训练数据；
* 生成对基础模型框架训练数据的引用或以其他方式识别该训练数据；
* 生成学术研究成果、期刊、教科书、专业书籍或课件。
