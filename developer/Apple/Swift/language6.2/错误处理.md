## 表示并抛出错误

Swift 中的错误是遵循`Error`协议的类型。在Swift中，枚举特别适合对一组相关的错误进行建模。

```Swift
enum VendingMachineError: Error {
    case invalidSelection
    case insufficientFunds(coinsNeeded: Int)
    case outOfStock
}

throw VendingMachineError.insufficientFunds(coinsNeeded: 5)
```

## 处理错误

Swift 提供了四种方式来处理错误。与其他语言中的异常处理机制不同，Swift 的错误处理不会展开调用堆栈，该过程可能带来较高的计算开销。因此 shrow 语句的执行性能与 return 语句相当。

### 继续向外抛出错误

在函数前面上使用`throws`关键字：

```swift
func canThrowErrors() throws -> String
```

调用抛出函数时，需使用`do-catch`、`try?`或`try!`语句。

### 使用 do-catch 处理错误

```swift 
do {
    try <#expression#>
    <#statements#>
} catch <#pattern 1#> {
    <#statements#>
} catch <#pattern 2#> where <#condition#> {
    <#statements#>
} catch <#pattern 3#>, <#pattern 4#> where <#condition#> {
    <#statements#>
} catch {
    <#statements#>
}
```

示例：

```swift
var vendingMachine = VendingMachine()
vendingMachine.coinsDeposited = 8
do {
    try buyFavoriteSnack(person: "Alice", vendingMachine: vendingMachine)
    print("Success! Yum.")
} catch VendingMachineError.invalidSelection {
    print("Invalid Selection.")
} catch VendingMachineError.outOfStock {
    print("Out of Stock.")
} catch VendingMachineError.insufficientFunds(let coinsNeeded) {
    print("Insufficient funds. Please insert an additional \(coinsNeeded) coins.")
} catch {
    print("Unexpected error: \(error).")
}
// Prints "Insufficient funds. Please insert an additional 2 coins."
```

catch 子句可以只处理部分错误情况，没被处理的错误继续抛出，直到被处理或到达调用栈的顶部，在顶部未被处理的错误成为运行时错误。

```swift
func nourish(with item: String) throws {
    do {
        try vendingMachine.vend(itemNamed: item)
    } catch is VendingMachineError {
        print("Couldn't buy that from the vending machine.")
    }
}

do {
    try nourish(with: "Beet-Flavored Chips")
} catch {
    print("Unexpected non-vending-machine-related error: \(error)")
}
// Prints "Couldn't buy that from the vending machine."
```

可以在 catch 后面列出多个相关的错误来一次处理多种错误：

```swift
func eat(item: String) throws {
    do {
        try vendingMachine.vend(itemNamed: item)
    } catch VendingMachineError.invalidSelection, VendingMachineError.insufficientFunds, VendingMachineError.outOfStock {
        print("Invalid selection, out of stock, or not enough money.")
    }
}
```

### 将错误转换为可选值

使用`try?`将错误转换为可选值。如果函数抛出错误，则表达式返回 nil。否则，表达式返回一个包含函数返回值的可选值。

```swift
func fetchData() -> Data? {
    if let data = try? fetchDataFromDisk() { return data }
    if let data = try? fetchDataFromServer() { return data }
    return nil
}
```

### 禁用错误传递

有时候我们确定调用不会抛出错误（例如，从已知路径加载图片），这时可以使用`try!`禁用错误传递。如果函数抛出错误，会触发运行时错误。

```swift
let photo = try! loadImage(atPath: "./Resources/John Appleseed.jpg")
```

## 指定错误类型

抛出函数声明时还可以指定错误类型，例如：

```swift
enum StatisticsError: Error {
    case noRatings
    case invalidRating(Int)
}

func summarize(_ ratings: [Int]) throws(StatisticsError) {
    guard !ratings.isEmpty else { throw .noRatings }

    var counts = [1: 0, 2: 0, 3: 0]
    for rating in ratings {
        guard rating > 0 && rating <= 3 else { throw .invalidRating(rating) }
        counts[rating]! += 1
    }

    print("*", counts[1]!, "-- **", counts[2]!, "-- ***", counts[3]!)
}
```

可以使用`Never`类型来表示一个函数不会抛出错误。例如：

```swift
func nonThrowingFunction() throws(Never) {
    // ...
}
```

在 do-catch 语句中，也可以指定可能抛出的错误类型。

```swift
let ratings = []
// 如果抛出的错误类型是已知的，这里的类型就可以省略了
do throws(StatisticsError) {
    try summarize(ratings)
} catch {
    switch error {
    case .noRatings:
        print("No ratings available")
    case .invalidRating(let rating):
        print("Invalid rating: \(rating)")
    }
}
```

## 指定清理操作

我们使用`defer`语句来指定在当前的代码块退出时执行的语句集合。defer 语句中不应该包含转移控制的语句，例如 break、return，或者抛出错误，多个 defer 语句按照声明的逆序执行。

```swift
func processFile(filename: String) throws {
    if exists(filename) {
        let file = open(filename)
        defer {
            close(file)
        }
        while let line = try file.readline() {
            // Work with the file.
        }
        // close(file) is called here, at the end of the scope.
    }
}
```
