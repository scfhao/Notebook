## State

State 是一个值，或者一些值，可以随时间改变，影响一个视图的行为、内容或布局。属性前加`@State`来声明。因为我们使用 state 属性保存特定view和它的子view的信息，所以我们总是把state创建为 private 属性。

可以把一个 binding 传递给 Control 来改变 State 的状态。binding 扮演了可变 state 的引用。当用户操作 Control 时，Control 会通过 binding 来改变 state 的值。在 state 变量或它的属性前添加`$`来创建一个 binding。

当 State 位于 App 结构中的属性时，表示该状态在应用的生命周期中初始化一次，如从传入App中的 environment 数据可以用 @State 定义。

## Binding

在视图中可以创建 binding 属性。

```Swift
@Binding var isSet: Bool
```

这样视图就可以改变从外部传入的 state 的值。

## Bindable

Bindable 是一个协议，用于创建可绑定的属性。

```Swift
var body: some View {
    @Bindable var modelData = modelData
```

## Observation

借助 Observation，SwiftUI 中的视图无需使用属性包装器或绑定即可支持数据变更。SwiftUI 能够监测所有可能影响视图的可观察属性变化，并在数据变更后显示正确的视图版本。

SwiftUI 只当一个可观察对象发生变化且视图的 body 直接读取了该可观察对象的属性时才会更新该视图。

```Swift
@Observable
class MyClass: ObservableObject {
}
```
