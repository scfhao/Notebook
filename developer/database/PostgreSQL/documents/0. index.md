本系列笔记为PostgreSQL官方文档摘要。

为了能够管理有关PostgreSQL的大量信息，本书被组织成了几个部分。每个部分都是针对不同层次的用户，或者说针对具有不同阶段PostgreSQL体验的用户：

* [第一部分](http://www.postgres.cn/docs/11/tutorial.html)是一个给新用户的非正式介绍。
* [第二部分](http://www.postgres.cn/docs/11/sql.html)记载了SQL查询语言环境，包括数据类型和函数，以及用户级别的性能调优。每个PostgreSQL用户都应该阅读这些内容。
* [第三部分](http://www.postgres.cn/docs/11/admin.html)描述服务器的安装和管理。每个运行PostgreSQL服务器的人，不管是个人使用还是为别人维护，都应该阅读这部分内容。
* [第四部分](http://www.postgres.cn/docs/11/client-interfaces.html)描述PostgreSQL客户端程序的编程接口。
* [第五部分](http://www.postgres.cn/docs/11/server-programming.html)包含为高级用户准备的信息，比如服务器的扩展能力等。其中的内容包括用户定义数据类型和函数等。
* [第六部分](http://www.postgres.cn/docs/11/reference.html)包含有关SQL命令、客户端和服务器程序的参考信息。这部分以按照命令或程序排序的结构化信息支持其他部分。
* [第七部分](http://www.postgres.cn/docs/11/internals.html)包含可用于PostgreSQL开发人员的各类信息。
