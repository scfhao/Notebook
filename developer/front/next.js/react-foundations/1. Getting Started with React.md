JSX 是 JavaScript 的语法扩展，允许在 JS 中使用类 html 语法，JSX 规则：

1. 被一个根元素包着，根元素可以是普通元素也可以是空元素。`<></>`就是空元素
2. 所有元素必须闭合
3. 大部分事物都要使用驼峰模式

浏览器无法理解 JSX，所以需要 JS 编译器如 Babel 来把你的JSX 代码转换为常规 JavaScript。

把 Babel 添加到项目：

```HTML
<script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
```

告诉 Babel 需要转换的代码，通过把 script 的类型改为`text/jsx`：

```HTML
<script type="text/jsx">
      const domNode = document.getElementById('app');
      const root = ReactDOM.createRoot(domNode);
      root.render(<h1>Develop. Preview. Ship.</h1>);
    </script>
```

## 添加状态交互

### 处理事件

```jsx
function HomePage() {

```

### 状态和钩子

React 中用来管理状态的钩子叫`useState()`，这个函数的返回值是数组，你可以使用数组解构来使用数组元素。数组中的第一个元素是状态的值，你可以给它设置任意名称`XXX`，数组中的第二个元素是用来更新状态值的函数，一般命名为`setXXX`，可以通过`useState`的参数给状态设置初始值。

```js
function HomePage() {
            const [likes, setLikes] = React.useState(0);

            function handleClick() {
                  setLikes(likes+1);
            }

            return (
                  <div>
                        <Header title="Develop. Preview. Ship." />
                        <button onClick={handleClick}>Likes ({likes})</button>
                  </div>
            );
      }
```
