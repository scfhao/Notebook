## 创建新项目

推荐使用[pnpm](https://pnpm.io/)作为包管理工具，因为它比`npm`和`yarn`更快更高效。

```shell
npm install -g pnpm
```

在项目文件夹下执行：

```shell
npx create-next-app@latest nextjs-dashboard --example "https://github.com/vercel/next-learn/tree/main/dashboard/starter-example" --use-pnpm
```

## 目录结构

* `/app`：包含全部的路由、组件和应用逻辑，我们的大多数工作在此进行。
* `/app/lib`：包含我们的应用中用到的函数，例如可重用的实用工具函数和数据抓取函数。
* `/app/ui`：包含应用中所有的 UI 组件，例如卡片、表格和表单。
* `/public`：包含应用中所有静态资源如图片。
* **Config Files** ：你还需要注意一下你的应用根目录中的配置文件夹，例如`next.config.js`。当你使用`create-next-app`开始新项目的时候大多数配置文件已经创建并预配置好了，在本教程中你不需要修改这些文件。

## TypeScript

为反映当前 Web 开发潮流，项目中使用了 TypeScript。

例如，在`/app/lib/definitions.ts`文件中，手动定义了数据库表中返回的数据类型，以 invoices 表为例：

```ts
export type Invoice = {
	id: string;
	custom_id: string;
	amount: number;
	date: string;
	// TypeScript 中的 union 类型，表示值只能是 'pending' 或 'paid'
	status: 'pending' | 'paid';
};
```

> 我们这里手动指定了数据类型，但为了更好的类型安全，我们推荐[Prisma](https://www.prisma.io/)或[Drizzle](https://orm.drizzle.team/)，他们可以基于数据库模式自动生成类型。
> Next.js 发现你的项目使用 TypeScript 后会自动安装必要的包和配置。同时 Next.js	也提供了一个[TypeScript plugin](https://nextjs.org/docs/app/building-your-application/configuring/typescript#typescript-plugin)插件，帮助自动完成和类型安全。

## 运行开发环境

运行`pnpm i`安装项目的包。

接着运行`pnpm dev`启动开发服务器。
