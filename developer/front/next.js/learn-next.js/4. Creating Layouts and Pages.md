## 内嵌路由

Next.js 使用文件系统路由，以文件夹作为内嵌路由。每个文件夹代表一个映射 URL 片段的路由片段。

`page.tsx`是一个导出一个 React 组件的特殊的 Next.js 文件。我们项目中已经存在的`/app/page.tsx`对应的路由是`/`。而`/app/dashboard/page.tsx`对应的路由是`/dashboard`。

## 创建 dashboard 页面

在`/app`目录下创建`dashboard`文件夹，然后在`dashboard`目录下创建`page.tsx`文件：

```tsx
export default function Page() {
	return <p>Dashboard Page</p>;
}
```

## 创建 dashboard 布局

在 Next.js 中，你可以使用一个特殊的`layout.tsx`文件创建可以在多个页面共享的 UI。

在`/dashboard`文件夹中，创建`layout.tsx`文件：

```tsx
import SideNav from '@/app/ui/dashboard/sidenav';

export default function Layout({ children }: { children: React.ReactNode}) {
	return (
		<div className="flex h-screen flex-col md:flex-row md:overflow-hidden">
			<div className="w-full flex-none md:w-64">
				<SideNav />
			</div>
			<div className="flex-grow p-6 md:overflow-y-auto md:p-12">{children}</div>
		</div>
	);
}
```

`<Layout />`组件接收一个`children`参数，可以是一个 page 也可以是另一个 layout。在当前的场景下，`/dashboard`中的 pages 会自动的内嵌到`<Layout />`中。

在 Next.js 中使用布局的优势是导航时只有页面组件更新而布局不需要重新渲染。

## 根布局

`/app/layout.tsx`是根布局，应用中所有的页面都会共用根布局，可以使用根布局修改`<html>`和`<body>`标签，或者添加元数据。
