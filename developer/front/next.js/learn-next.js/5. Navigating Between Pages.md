## `<Link>`组件

在 Next.js 中，可以使用`<Link />`组件链接应用中的页面。`<Link>`允许你做客户端导航。

`<Link>`标签的使用很简单，只需要把以前的`<a>`标签替换成`<Link>`即可，使用`<Link>`的好处是网页不会整体刷新，而是局部刷新（Safari 下浏览器地址栏不会有进度条显示，但是地址会变）。

```tsx
import {
  UserGroupIcon,
  HomeIcon,
  DocumentDuplicateIcon,
} from '@heroicons/react/24/outline';
import Link from 'next/link';
 
// ...
 
export default function NavLinks() {
  return (
    <>
      {links.map((link) => {
        const LinkIcon = link.icon;
        return (
          <Link
            key={link.name}
            href={link.href}
            className="flex h-[48px] grow items-center justify-center gap-2 rounded-md bg-gray-50 p-3 text-sm font-medium hover:bg-sky-100 hover:text-blue-600 md:flex-none md:justify-start md:p-2 md:px-3"
          >
            <LinkIcon className="w-6" />
            <p className="hidden md:block">{link.name}</p>
          </Link>
        );
      })}
    </>
  );
} 
```

## 自动代码分割和预取

为了改善导航体验，Next.js 会自动按路径分段对应用程序进行代码拆分。这与传统的 React [SPA](https://developer.mozilla.org/en-US/docs/Glossary/SPA) 不同，在传统的 React SPA 中，浏览器会在初始加载时加载所有应用程序代码。

通过路由分割代码意味着页面变得孤立。如果某个页面出错，应用程序的其他部分仍能正常工作。

此外，在生产过程中，只要`<Link>`组件出现在浏览器的视口中，Next.js 就会在后台自动预取链接路径的代码。当用户点击链接时，目标页面的代码已经在后台加载，这就是页面转换近乎即时的原因！

## 模式：显示活动链接

一种常见的用户界面模式是显示一个活动链接，向用户指示当前所在的页面。为此，您需要从 URL 获取用户的当前路径。Next.js 提供了一个名为`usePathname()`的钩子，您可以用它来检查路径并实现这种模式。

> 这里说的活动链接就是菜单中当前访问的菜单链接。

由于[usePathname()](https://nextjs.org/docs/app/api-reference/functions/use-pathname)是一个钩子，我们需要把`nav-links.tsx`转为客户端组件，然后引入`usePathname()`，在使用前面 CSS 章节介绍的`clsx`库，在不同场景下显示不同样式的链接。最终的`nav-links.tsx`内容如下：

```tsx
'use client';

import {
	UserGroupIcon,
	HomeIcon,
	DocumentDuplicateIcon
} from '@heroicons/react/24/outline';
import Link from 'next/link';
import { usePathname } from 'next/navigation';
import clsx from 'clsx';

export default function NavLinks() {
	const pathname = usePathname();

	return (
		<>
			{links.map((link) => {
				const LinkIcon = link.icon;
				return (
					<Link
						key={link.name}
						href={link.href}
						className={clsx(
							'flex h-[48px] grow items-center justify-center gap-2 rounded-md bg-gray-50 p-3 text-sm font-medium hover:bg-sky-100 hover:text-blue-600 md:flex-none md:justify-start md:p-2 md:px-3',
              {
                'bg-sky-100 text-blue-600': pathname === link.href,
              },
						)}
					>
						<LinkIcon className="w-6" />
						<p className="hidden md:block">{link.name}</p>
					</Link>
				);
			})}
		</>;
	);
}
```
