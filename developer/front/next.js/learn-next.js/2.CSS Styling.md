## 全局样式

你可以在`/app/ui/global.css`文件中为应用中所有路由添加 CSS 规则。

在 `/app/layout.tsx`中导入`global.css`文件：

```tsx
import '@/app/ui/global.css';
```

## Tailwind

使用`create-next-app`开始新项目时，Next.js 会问你是否想要使用 Tailwind，如果选择`yes`，Next.js 会自动安装必要的包并为你的应用配置 Tailwind。

如果你更喜欢把 CSS 写在单独的文件里，CSS 模块是不错的可选项。

## CSS 模块

CSS 模块通过自动创建唯一的类名来允许你将 CSS 作用于一个组件，所以你不需要担心样式冲突问题。

本课程中会继续使用 Tailwind，但让我们花一点时间来看一下如何用 CSS 模块来实现同样的效果。

在`/app/ui`中，创建名为`home.module.css`的新文件：

```css
.shape {
	height: 0;
	width: 0;
	border-bottom: 30px solid black;
	border-left: 20px solid transparent;
	border-right: 20px solid transparent;
}
```

然后在`/app/page.tsx`文件中导入样式并替换`<div>`的 Tailwind 类名。

```tsx
import AcmeLogo from '@/app/ui/acme-logo';
import { ArrowRightIcon } from '@heroicons/react/24/outline';
import Link from 'next/link';
import styles from '@/app/ui/home.module.css';
 
export default function Page() {
  return (
    <main className="flex min-h-screen flex-col p-6">
      <div className={styles.shape} />
    // ...
  )
}
```

Tailwind 和 CSS 模块是为 Next.js 应用添加样式的两种最常用的方法。可以按个人便好使用其中之一，或两个同时用。

## 使用`clsx`库切换类名

可能需要根据状态或别的条件来选择样式。[clsx](https://www.npmjs.com/package/clsx)就是让你轻松切换类名的库。这是它的基础用法，详见[文档](https://github.com/lukeed/clsx)：

* 假设你想要创建一个接收`status`的名为`InvoiceStatus`的组件。`status`值为`'pending'`或`'paid'`。
* 如果是`'paid'`，你想使用绿色。反之使用灰色。

```tsx
import clsx from 'clsx';

export default function InvoiceStatus({ status }: { status: string}) {
	return (
		<span className={clsx(
			'inline-flex items-center rounded-full px-2 py-1 text-sm',
			{
				'bg-gray-100 text-gray-500': status === 'pending',
				'bg-green-500 text-white': status === 'paid',
			},
		)}>
)}
```
