## 什么是 streaming？

流式传输是一种数据传输技术，可将路由分解成较小的 “块”，并在准备就绪时逐步从服务器将其传输到客户端。

> scfhao: 感觉这个 streaming 翻译为加载提示更合适

通过流式传输，可以防止缓慢的数据请求阻塞整个页面。这样，用户就可以看到页面的部分内容并与之交互，而无需在向用户显示任何用户界面之前等待加载所有数据。

流与 React 的组件模型配合得很好，因为每个组件都可以被视为一个*块*。

Next.js 中，有两种方式可以实现流：

1. 在页面级，使用`loading.tsx`文件。
2. 对于具体的组件，使用`<Suspense>`。

## 用`loading.tsx`流整个页面

在`/app/dashboard`目录下，创建`loading.tsx`：

```tsx
export default function Loading() {
	return <div>Loading...</div>;
}
```

刷新[http://localhost:3000/dashboard](http://localhost:3000/dashboard)，就能看到这个效果。

## 添加加载骨架

加载骨架是用户界面的简化版本。许多网站使用它们作为占位符（或后备），向用户提示内容正在加载。您在`loading.tsx`中添加的任何用户界面都将作为静态文件的一部分嵌入，并首先发送。然后，其余的动态内容将从服务器流式传输到客户端。

在`loading.tsx`文件中，导入一个名为`<DashboardSkeleton>`的新组件：

```tsx
import DashboardSkeleton from '@/app/ui/skeletons';

export default function Loading() {
	return <DashboardSkeleton />;
}
```

## 修复路由组加载骨架的错误

像布局文件一样，`loading.tsx`文件也会被应用到所在目录下的所有页面，但我们现在并不希望当前的这个加载页面应用到`invoices/page.tsx`和`/customers/page.tsx`。

我们可以通过[路由组](https://nextjs.org/docs/app/building-your-application/routing/route-groups)来改变这种情况。在仪表盘文件夹内新建一个名为`/(overview)`的文件夹。然后，将`loading.tsx`和`page.tsx`文件移到该文件夹内

现在，`loading.tsx`文件只适用于仪表盘概览页面。

路由组允许你在不影响 URL 路径结构的情况下将文件组织成逻辑组。使用括号`（）`创建新文件夹时，名称不会包含在 URL 路径中。因此`/dashboard/(overview)/page.tsx`就变成了`/dashboard`。

在这里，你使用路由组来确保`loading.tsx`只适用于仪表盘概览页面。不过，您也可以使用路由组将应用程序分隔成不同部分（例如`（营销）`路由和`（商店）`路由），或按大型应用程序的团队来分隔。

## 流组件

Suspense 可让您推迟渲染应用程序的某些部分，直到满足某些条件（如加载数据完成）。你可以用 Suspense 封装你的动态组件。然后，在动态组件加载时，将一个后备组件传递给它来显示。

从 React 中导入`<Suspense>`，并将`<RevenueChart />`其封装在其中。您可以将名为`<RevenueChartSkeleton>`的后备组件传递给它。

```tsx
import { Suspense } from 'react';
import { RevenueChartSkeleton } from '@/app/ui/skeletons';

<Suspense fallback={<RevenueChartSkeleton />}>
  <RevenueChart />
</Suspense>
```

## 组件分组

太好了！现在，您需要用 Suspense 将`<Card>`组件封装起来。您可以为每张卡片获取数据，但这样做可能会在卡片载入时产生 “啪啪 ”的效果，这会给用户带来视觉上的不适。

要创建更多的交错效果，可以使用包装组件对卡片进行分组。这意味着静态`<SideNav/>`将首先显示，然后是卡片等。

在你的`page.tsx`文件中：

1. 删除`<Card>`组件。
2. 删除`fetchCardData()`函数。
3. 导入名为`<CardWrapper />`的新封装组件。
4. 导入名为`<CardsSkeleton />`的新骨架组件。
5. 将`<CardWrapper />`包裹在 Suspense 中。

```tsx
import CardWrapper from '@/app/ui/dashboard/cards';
// ...
import {
  RevenueChartSkeleton,
  LatestInvoicesSkeleton,
  CardsSkeleton,
} from '@/app/ui/skeletons';
 
export default async function Page() {
  return (
    <main>
      <h1 className={`${lusitana.className} mb-4 text-xl md:text-2xl`}>
        Dashboard
      </h1>
      <div className="grid gap-6 sm:grid-cols-2 lg:grid-cols-4">
        <Suspense fallback={<CardsSkeleton />}>
          <CardWrapper />
        </Suspense>
      </div>
      // ...
    </main>
  );
}
```

然后，进入文件`/app/ui/dashboard/cards.tsx`，导入`fetchCardData()`函数，并包在`<CardWrapper/>`组件中。确保取消该组件中任何必要代码的注释。

```tsx
// ...
import { fetchCardData } from '@/app/lib/data';
 
// ...
 
export default async function CardWrapper() {
  const {
    numberOfInvoices,
    numberOfCustomers,
    totalPaidInvoices,
    totalPendingInvoices,
  } = await fetchCardData();
 
  return (
    <>
      <Card title="Collected" value={totalPaidInvoices} type="collected" />
      <Card title="Pending" value={totalPendingInvoices} type="pending" />
      <Card title="Total Invoices" value={numberOfInvoices} type="invoices" />
      <Card
        title="Total Customers"
        value={numberOfCustomers}
        type="customers"
      />
    </>
  );
}
```

刷新页面，就可以看到全部的卡片同时载入。
