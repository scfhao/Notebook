## Tailwind CLI

对于零基础来说，最简单快速的开始使用 Tailwind CSS 的方法是使用 Tailwind 命令行工具。如果你不想通过 Node.js 使用它，也提供了[独立的可执行程序](https://tailwindcss.com/blog/standalone-cli)。

1. 安装 Tailwind CSS

```Bash
npm install tailwindcss @tailwindcss/cli
```

2. 在你的主CSS文件(src/input.css)中引入 Tailwind

```Bash
@import "tailwindcss";
```

3. 运行命令行工具扫描源文件中的类并编译 CSS

```Bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```

4. 在`<head>`中添加编译后的 CSS 文件开始使用 Tailwind 的工具类样式。

```Bash
<!doctype html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link href="./output.css" rel="stylesheet">
</head>
<body>
  <h1 class="text-3xl font-bold underline">
    Hello world!
  </h1>
</body>
</html>
```

## 使用独立的命令行程序

1. 下载

```
curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-arm64
chmod +x tailwindcss-macos-arm64
mv tailwindcss-macos-arm64 tailwindcss
```

```
# Create a tailwind.config.js file
./tailwindcss init

# Start a watcher
./tailwindcss -i input.css -o output.css --watch

# Compile and minify your CSS for production
./tailwindcss -i input.css -o output.css --minify
```

## 使用CDN

在 HTML 文件的`<head>`标签中引入 CDN 脚本

```HTML
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```
