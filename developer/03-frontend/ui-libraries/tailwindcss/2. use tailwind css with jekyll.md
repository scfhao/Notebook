## 环境准备

```Gemfile
group :jekyll_plugins do
  gem 'jekyll-postcss'
end
```

```_config.yml
plugins:
  - jekyll-postcss
```

```
$ bundle install
```

```
$ npm install tailwindcss @tailwindcss/typography cssnano postcss postcss-import autoprefixer --save-dev
```

## 创建 PostCSS 配置文件

在项目根目录创建：postcss.config.js

```
module.exports = {
	plugins: [
		require('postcss-import'),
		require('tailwindcss'),
		require('autoprefixer'),
		...(process.env.JEKYLL_ENV == "production"
		  ? [require('cssnano')({ preset: 'default' })]
		  : [])
	]
};
```

此配置使用 postcss-import 来启用 @import 语句的构建时间处理。如果您在 Tailwind 中使用了上述未列出的其他插件，请务必检查预处理器的使用情况。

## 创建 Tailwind 配置文件

在项目根目录创建：tailwind.config.js

```
module.exports = {
	purge: [
		'./_includes/**/*.html',
		'./_layouts/**/*.html',
		'./_post/*.md',
		'./*.html',
	],
	darkMode: false,
	theme: {
		extend: {},
	},
	variants: {},
	plugins: [
		require('@tailwindcss/typography')
	],
}
```

## 在你的CSS中引入 Tailwind

```
---
---
@import "tailwindcss/base";
@import "tailwindcss/components";
@import "tailwindcss/utilities";
```

## 部署

```
JEKYLL_ENV=production NODE_ENV=production bundle exec jekyll build
```
