## 添加私有字体

在`/app/ui`文件夹下，创建名为`fonts.ts`的新文件。从`next/font/google`模块导入`Inter`字体（用作私有字体）。然后指定需要加载的子集，例如`latin`：

```ts
import { Inter } from 'next/font/google';

export const inter = Inter({ subsets: ['latin'] });
```

最后，向`/app/layout.tsx`中的`<body>`元素添加字体：

```tsx
import { inter } from '@/app/ui/fonts';

<body className={`${inter.className} antialiased`}>{children}</body>
```

这里还添加了 Tailwind 的`antialiased`可以让字体载入更平滑。

## `<Image>`组件

`<Image>`组件是 HTML `<img>`标签的扩展，提供了自动图片优化的功能，例如：

* 防止在加载图像时版面自动移动。
* 调整图片大小，避免将大图片传输到视口较小的设备上。
* 默认懒加载图像（图像在进入视口时加载）。
* 在浏览器支持的情况下，以[WebP](https://developer.mozilla.org/en-US/docs/Web/Media/Formats/Image_types#webp)和[AVIF](https://developer.mozilla.org/en-US/docs/Web/Media/Formats/Image_types#avif_image)等现代格式提供图像。

## 添加图片

在`/app/page.tsx`文件中，导入`next/image`组件，然后添加图片：

```tsx
import Image from 'next/image';

<Image
	src="/hero-desktop.png"
	width={1000}
	height={760}
	className="hidden md:block"
	alt="Screenshots of the dashboard project showing desktop version"
/>
```

在这里，我们把宽和高分别设置为`1000`和`760`像素。为图片设置宽和高是避免布局移位的最佳实践，宽高比一般设置为源图片的宽高比。

> src 中的`/`对应的项目的`/public`目录。
