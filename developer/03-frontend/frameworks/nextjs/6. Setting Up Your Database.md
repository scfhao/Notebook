1. 将代码上传到 GitHub。
2. 将仓库导入 Vercel。
3. 一件部署。
4. 每当你有新修改提交到 main 分之，Vercel将会自动重新部署你的应用。

> 默认分配的vercel.app域名本地访问不了（2024），绑定自己的域名后自己的域名可以访问。

## 创建 Postgres 数据库

在 vercel 项目主页里，选择 Storage 标签，选择存储类型，比如 Postgres，可以创建一个数据库。创建好数据库后，在数据库的 Quickstart 中找到`.env.local`，复制其中的代码片段。

把新项目中的`.env.example`文件重命名为`.env`，粘贴从 Vercel 复制的内容。

> 确保`.gitignore`文件中已经加入了`.env`，避免把数据库密钥信息提交到 GitHub。

最后，运行`pnpm i @vercel/postgres`安装[Vercel Postgres SDK](https://vercel.com/docs/storage/vercel-postgres/sdk)。

## 添加初始数据

在`/app`中，有一个名为`seed`的文件夹。取消注释该文件。该文件夹包含一个名为`route.ts`的[Next.js 路由处理程序](https://nextjs.org/docs/app/building-your-application/routing/route-handlers)，将用于为数据库添加种子。这将创建一个服务器端端点，您可以在浏览器中访问该端点，开始填充数据库。

使用`pnpm run dev`确保本地开发服务器正在运行，然后在浏览器中导航到`localhost:3000/seed`。完成后，您将在浏览器中看到 “数据库播种成功”的信息。完成后，即可删除此文件。

## 查看数据，执行查询

数据库初始化完成后，在 Vercel 项目 Storage 的 Data 区域可以看到有“Browse”和“Query”两个操作，其中 Browse 可以浏览数据库中各表的数据，Query 中可以执行 SQL 语句（包含删表语句，所以请谨慎操作）。
