需要先安装 Node.js（Node.js 中包含 npm，npm 是 Node 的包管理工具)

1. 使用 Create React Native App

```bash
$ npm install -g create-react-native-app
$ create-react-native-app AwesomeProject
$ cd AwesomeProject
# 这会启动一个开发服务并在终端打印一个二维码
$ npm start
```

在 iOS 或安卓手机上安装 [Expo](https://expo.io)，手机与电脑连接同一个无线网络，使用 Expo 应用扫描生成的二维码。当修改并保存修改后，应用会自动重新加载。这样创建的 App 没用到任何原生的东西，也不能在模拟器上运行。

2. 使用 React Native CLI

```bash
$ npm install -g react-native-cli
$ react-native init AwesomeProject
$ cd AwesomeProject
$ react-native run-ios
```

如果遇到像`Cannot find module 'npmlog'`的错误，尝试直接安装npm`curl -0 -L https://npmjs.org/install.sh | sudo sh`.

按如上步骤创建项目，运行时报错：TransformError [...]  (While processing preset: node_modules [... \\babel-preset-react-native\\index.js")

解决方案，在项目目录中安装`babel-preset-react-native@2.1.0`

```bash
# 用npm 安装
$ npm install babel-preset-react-native@2.1.0

# 用 yarn 安装（yarn需要单独安装一下）
$ yarn add babel-preset-react-native@2.1.0

# 对应的卸载方法如下：
$ npm uninstall babel-preset-react-native
$ yarn remove babel-preset-react-native
```
