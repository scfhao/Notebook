# 配置服务监听端口

## macOS

1. 修改 ssh 服务的端口`sudo vi /etc/services`：
2. 重启服务：

```bash
sudo launchctl unload -w /System/Library/LaunchDaemons/ssh.plist
sudo launchctl load -w /System/Library/LaunchDaemons/ssh.plist
```

## Linux

修改 `/etc/ssh/sshd_config` 文件，将 `Port 22` 改为 `Port 2222` 即可。

重启sshd：

```bash
# 不同发行版的命令：
sudo systemctl restart sshd      # systemd (大多数现代 Linux)
# 或
sudo service ssh restart         # SysV init
# 或
sudo /etc/init.d/ssh restart     # 老版本
```

# 配置客户端默认使用的端口

修改 `/etc/ssh/ssh_config` 文件中的 `Port 22`。

> 在macOS上，通过修改`/etc/services`文件修改ssh协议的默认端口，同时会对服务端和客户端生效，这时需要通过修改`/etc/ssh/ssh_config`来指定客户端默认的端口。
