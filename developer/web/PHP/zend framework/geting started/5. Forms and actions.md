## 添加新专辑

现在我们可以编写功能来添加新相册。 这部分有两点：

* 显示一个表单供用户提供详细信息。
* 处理表单提交并存储到数据库。

我们将使用 zend-form 来做到这一点。zend-form 管理各种表单输入及验证，后者由 zend-inputfilter 组件处理。 我们将从创建一个继承自 从 Zend\Form\Form 的类 Album\Form\AlbumForm 开始。使用以下内容创建文件`module/Album/src/Form/AlbumForm.php`：

```PHP
namespace Album\Form;

use Zend\Form\Form;

class AlbumForm extends Form
{
    public function __construct($name = null)
    {
        // We will ignore the name provided to the constructor
        parent::__construct('album');

        $this->add([
            'name' => 'id',
            'type' => 'hidden',
        ]);
        $this->add([
            'name' => 'title',
            'type' => 'text',
            'options' => [
                'label' => 'Title',
            ],
        ]);
        $this->add([
            'name' => 'artist',
            'type' => 'text',
            'options' => [
                'label' => 'Artist',
            ],
        ]);
        $this->add([
            'name' => 'submit',
            'type' => 'submit',
            'attributes' => [
                'value' => 'Go',
                'id'    => 'submitbutton',
            ],
        ]);
    }
}
```

在 AlbumForm 的构造函数中，我们做了几件事情。首先，我们调用父类的构造函数来设置表单的名称。 然后，我们创建四个表单元素：标识，标题，艺术家和提交按钮。对于每个项目，我们设置各种属性和选项，包括要显示的标签。

> 表单方法
> HTML表单可以使用 POST 和 GET 发送。zend-form 默认为POST; 因此您不必在明确设置此选项。 如果您想将其更改为 GET，请在构造函数中设置方法属性：
> `$this->setAttribute('method', 'GET');`

我们还需要为此表单设置验证。zend-inputfilter 为输入验证提供了一个通用机制。 它还提供了一个接口 InputFilterAwareInterface，它将使用 zend-form 将输入过滤器绑定到给定的表单。我们现在将此功能添加到我们的专辑类中。

```PHP
// module/Album/src/Model/Album.php:
namespace Album\Model;

// Add the following import statements:
use DomainException;
use Zend\Filter\StringTrim;
use Zend\Filter\StripTags;
use Zend\Filter\ToInt;
use Zend\InputFilter\InputFilter;
use Zend\InputFilter\InputFilterAwareInterface;
use Zend\InputFilter\InputFilterInterface;
use Zend\Validator\StringLength;

class Album implements InputFilterAwareInterface
{
    public $id;
    public $artist;
    public $title;

    // Add this property:
    private $inputFilter;

    public function exchangeArray(array $data)
    {
        $this->id     = !empty($data['id']) ? $data['id'] : null;
        $this->artist = !empty($data['artist']) ? $data['artist'] : null;
        $this->title  = !empty($data['title']) ? $data['title'] : null;
    }

    /* Add the following methods: */

    public function setInputFilter(InputFilterInterface $inputFilter)
    {
        throw new DomainException(sprintf(
            '%s does not allow injection of an alternate input filter',
            __CLASS__
        ));
    }

    public function getInputFilter()
    {
        if ($this->inputFilter) {
            return $this->inputFilter;
        }

        $inputFilter = new InputFilter();

        $inputFilter->add([
            'name' => 'id',
            'required' => true,
            'filters' => [
                ['name' => ToInt::class],
            ],
        ]);

        $inputFilter->add([
            'name' => 'artist',
            'required' => true,
            'filters' => [
                ['name' => StripTags::class],
                ['name' => StringTrim::class],
            ],
            'validators' => [
                [
                    'name' => StringLength::class,
                    'options' => [
                        'encoding' => 'UTF-8',
                        'min' => 1,
                        'max' => 100,
                    ],
                ],
            ],
        ]);

        $inputFilter->add([
            'name' => 'title',
            'required' => true,
            'filters' => [
                ['name' => StripTags::class],
                ['name' => StringTrim::class],
            ],
            'validators' => [
                [
                    'name' => StringLength::class,
                    'options' => [
                        'encoding' => 'UTF-8',
                        'min' => 1,
                        'max' => 100,
                    ],
                ],
            ],
        ]);

        $this->inputFilter = $inputFilter;
        return $this->inputFilter;
    }
}
```

`InputFilterAwareInterface`定义了两个方法：`setInputFilter()`和`getInputFilter()`。 我们只需要实现`getInputFilter()`，所以从`setInputFilter()`中抛出了一个异常。

在`getInputFilter()`中，我们实例化一个`InputFilter`，然后添加我们需要的输入。 我们为每个想要过滤或验证的属性添加一个输入。对于id字段，我们添加一个`int`过滤器，因为我们只需要整数。 对于文本元素，我们添加两个过滤器`StripTags`和`StringTrim`，以删除不需要的HTML和不必要的空白。 我们还将它们设置为必需的，并添加一个`StringLength`验证程序，以确保用户输入的字符数量不超过我们可以存储到数据库中的数量。

我们现在需要让表单显示，然后在提交时处理它。这是在`AlbumController::addAction()`中完成的：

```PHP
// module/Album/src/Controller/AlbumController.php:

// Add the following import statements at the top of the file:
use Album\Form\AlbumForm;
use Album\Model\Album;

class AlbumController extends AbstractActionController
{
    /* ... */

    /* Update the following method to read as follows: */
    public function addAction()
    {
        $form = new AlbumForm();
        $form->get('submit')->setValue('Add');

        $request = $this->getRequest();

        if (! $request->isPost()) {
            return ['form' => $form];
        }

        $album = new Album();
        $form->setInputFilter($album->getInputFilter());
        $form->setData($request->getPost());

        if (! $form->isValid()) {
            return ['form' => $form];
        }

        $album->exchangeArray($form->getData());
        $this->table->saveAlbum($album);
        return $this->redirect()->toRoute('album');
    }

    /* ... */
}
```

在将`Album`和`AlbumForm`类添加到导入列表后，我们实现了`addAction()`。 让我们来看看`addAction()`代码的更多细节：

```PHP
$form = new AlbumForm();
$form->get('submit')->setValue('Add');
```

我们实例化`AlbumForm`并将提交按钮上的标签设置为“添加”。 我们这样做是因为我们希望在编辑相册时重新使用表单并使用不同的标签。

```PHP
$request = $this->getRequest();

if (! $request->isPost()) {
    return ['form' => $form];
}
```

如果请求不是POST请求，则没有表单数据提交，我们需要显示表单。 如果需要，zend-mvc允许你返回一个数据数组代替视图模型; 如果你这样做，数组将被用来创建一个视图模型。

```PHP
$album = new Album();
$form->setInputFilter($album->getInputFilter());
$form->setData($request->getPost());
```

此时，我们知道我们有表单提交。 我们创建一个Album实例，并将其输入过滤器传递给表单; 另外，我们将提交的数据从请求实例传递给表单。

```PHP
if (! $form->isValid()) {
    return ['form' => $form];
}
```

如果表单验证失败，我们希望重新显示表单。 此时，表单中包含有关未通过验证的字段以及原因，以及此信息将传送到视图图层的信息。

```PHP
$album->exchangeArray($form->getData());
$this->table->saveAlbum($album);
```

如果表单有效，那么我们使用`saveAlbum()`从表单中获取数据并存储到模型中。

```PHP
return $this->redirect()->toRoute('album');
```

在保存新的专辑行后，我们使用`Redirect`控制器插件将其重定向回专辑列表。

我们现在需要在add.phtml视图脚本中渲染表单：

```PHP
<?php
// module/Album/view/album/album/add.phtml:

$title = 'Add new album';
$this->headTitle($title);
?>
<h1><?= $this->escapeHtml($title) ?></h1>
<?php
$form->setAttribute('action', $this->url('album', ['action' => 'add']));
$form->prepare();

echo $this->form()->openTag($form);
echo $this->formHidden($form->get('id'));
echo $this->formRow($form->get('title'));
echo $this->formRow($form->get('artist'));
echo $this->formSubmit($form->get('submit'));
echo $this->form()->closeTag();
```

我们像以前一样显示标题，然后我们呈现表单。 zend-form 提供了几个视图助手来使这个更容易一些。 `form()`视图帮助器有一个`openTag()`和`closeTag()`方法，我们用它来打开和关闭表单。 然后，对于每个带有标签的元素，我们可以使用`formRow()`来渲染标签，输入和任何验证错误消息; 对于独立且没有验证规则的两个元素，我们使用`formHidden()`和`formSubmit()`。

或者，通过使用捆绑的`formCollection`视图助手，可以简化呈现表单的过程。 例如，在上面的视图脚本中，将所有表单呈现回显语句替换为：

```PHP
echo $this->formCollection($form);
```

这将遍历表单结构，为每个元素调用适当的标签，元素和错误视图助手，但是您仍然必须使用打开和关闭窗体标签来封装`formCollection($form)`。这有助于在窗体的默认HTML呈现可接受的情况下降低视图脚本的复杂性。

## 编辑专辑

编辑专辑几乎与添加专辑相同，因此代码非常相似。 这次我们在`AlbumController`中使用`editAction()`：

```PHP
// module/Album/src/Controller/AlbumController.php:
// ...

    public function editAction()
    {
        $id = (int) $this->params()->fromRoute('id', 0);

        if (0 === $id) {
            return $this->redirect()->toRoute('album', ['action' => 'add']);
        }

        // Retrieve the album with the specified id. Doing so raises
        // an exception if the album is not found, which should result
        // in redirecting to the landing page.
        try {
            $album = $this->table->getAlbum($id);
        } catch (\Exception $e) {
            return $this->redirect()->toRoute('album', ['action' => 'index']);
        }

        $form = new AlbumForm();
        $form->bind($album);
        $form->get('submit')->setAttribute('value', 'Edit');

        $request = $this->getRequest();
        $viewData = ['id' => $id, 'form' => $form];

        if (! $request->isPost()) {
            return $viewData;
        }

        $form->setInputFilter($album->getInputFilter());
        $form->setData($request->getPost());

        if (! $form->isValid()) {
            return $viewData;
        }

        $this->table->saveAlbum($album);

        // Redirect to album list
        return $this->redirect()->toRoute('album', ['action' => 'index']);
    }
```

这段代码看起来应该很熟悉。我们来看看添加专辑的不同之处。 首先，我们查找匹配路由中的`id`并使用它来加载要编辑的专辑：

```PHP
$id = (int) $this->params()->fromRoute('id', 0);

if (0 === $id) {
    return $this->redirect()->toRoute('album', ['action' => 'add']);
}

// Retrieve the album with the specified id. Doing so raises
// an exception if the album is not found, which should result
// in redirecting to the landing page.
try {
    $album = $this->table->getAlbum($id);
} catch (\Exception $e) {
    return $this->redirect()->toRoute('album', ['action' => 'index']);
}
```

`params`是一个控制器插件，它提供了一种方便的方式从匹配的路线中检索参数。我们用它从我们在相册模块的`module.config.php`中创建的路线中检索`id`。如果`id`为零，那么我们重定向到添加动作，否则，我们继续从数据库获取专辑实体。

我们必须检查以确保具有指定`id`的相册实际上可以找到。如果不能，那么数据访问方法会抛出异常。我们捕获该异常并将用户重新路由到索引页面。

```PHP
$form = new AlbumForm();
$form->bind($album);
$form->get('submit')->setAttribute('value', 'Edit');
```

表单的`bind()`方法将模型附加到表单。这用于两种方式：

* 显示表单时，每个元素的初始值都从模型中提取。
* 在`isValid()`中成功验证之后，表单中的数据将被放回到模型中。

这些操作使用`hydrator`对象完成。有许多 hydrators，但默认的是`Zend\Hydrator\ArraySerializable`，它希望在模型中找到两个方法：`getArrayCopy()`和`exchangeArray()`。我们已经在我们的`Album`实体中编写了`exchangeArray()`，所以我们现在需要编写`getArrayCopy()`：

```PHP
// module/Album/src/Model/Album.php:
// ...

    public function exchangeArray($data)
    {
        $this->id     = isset($data['id']) ? $data['id'] : null;
        $this->artist = isset($data['artist']) ? $data['artist'] : null;
        $this->title  = isset($data['title']) ? $data['title'] : null;
    }

    // Add the following method:
    public function getArrayCopy()
    {
        return [
            'id'     => $this->id,
            'artist' => $this->artist,
            'title'  => $this->title,
        ];
    }

// ...
```

由于使用`bind()`和`hydrator`，我们不需要将表单的数据填充到`$album`中，因为我们可以调用映射器的`saveAlbum()`方法将更改存回到数据库。

视图模板`edit.phtml`与添加专辑非常相似：


唯一的变化是使用“编辑相册”标题，并使用当前相册标识将表单的动作也设置为“编辑”动作。

## 删除专辑

为了完善我们的应用程序，我们需要添加删除。我们的列表页面上的每个专辑旁边都有一个“删除”链接，而单纯的方法是在点击时进行删除。这将是错误的。记住我们的HTTP规范，我们记得你不应该使用GET做不可逆的动作，而应该使用POST。

当用户点击删除时，我们将显示一个确认表单，如果他们点击“是”，我们将删除。由于表单很简单，我们将直接将其编码到我们的视图中（zend-form毕竟是可选的！）。

让我们从`AlbumController::deleteAction()`中的动作代码开始：

```PHP
// module/Album/src/Album/Controller/AlbumController.php:
//...
    // Add content to the following method:
    public function deleteAction()
    {
        $id = (int) $this->params()->fromRoute('id', 0);
        if (!$id) {
            return $this->redirect()->toRoute('album');
        }

        $request = $this->getRequest();
        if ($request->isPost()) {
            $del = $request->getPost('del', 'No');

            if ($del == 'Yes') {
                $id = (int) $request->getPost('id');
                $this->table->deleteAlbum($id);
            }

            // Redirect to list of albums
            return $this->redirect()->toRoute('album');
        }

        return [
            'id'    => $id,
            'album' => $this->table->getAlbum($id),
        ];
    }
//...
```

和以前一样，我们从匹配的路由中获取`id`，并检查请求对象的`isPost()`以确定是否显示确认页面或删除相册。我们使用表格对象使用`deleteAlbum()`方法删除行，然后重新导回相册列表。如果请求不是POST，那么我们检索正确的数据库记录并将其与`id`一起分配给视图。

视图脚本是一个简单的形式：

```PHP
<?php
// module/Album/view/album/album/delete.phtml:

$title = 'Delete album';
$url   = $this->url('album', ['action' => 'delete', 'id' => $id]);

$this->headTitle($title);
?>
<h1><?= $this->escapeHtml($title) ?></h1>

<p>
    Are you sure that you want to delete
    "<?= $this->escapeHtml($album->title) ?>" by
    "<?= $this->escapeHtml($album->artist) ?>"?
</p>

<form action="<?= $url ?>" method="post">
<div class="form-group">
    <input type="hidden" name="id" value="<?= (int) $album->id ?>" />
    <input type="submit" class="btn btn-danger" name="del" value="Yes" />
    <input type="submit" class="btn btn-success" name="del" value="No" />
</div>
</form>
```

在这个脚本中，我们向用户显示一条确认信息，然后显示一个带有“是”和“否”按钮的表单。 在行动中，我们在删除时专门检查了“是”值。

## 确保主页显示专辑列表

最后一点。目前，主页`http://zf-tutorial.localhost/`不显示相册列表。

这是由于在应用程序模块的`module.config.php`中设置了一个路由。 要改变它，打开`module/Application/config/module.config.php`并找到 home 路由：

```PHP
'home' => [
    'type' => \Zend\Router\Http\Literal::class,
    'options' => [
        'route'    => '/',
        'defaults' => [
            'controller' => Controller\IndexController::class,
            'action'     => 'index',
        ],
    ],
],
```

在文件顶部导入`Album\Controller\AlbumController`：

```PHP
use Album\Controller\AlbumController;
```

并将`controller`从`Controller\IndexController::class`更改为`AlbumController::class`：

```PHP
'home' => [
    'type' => \Zend\Router\Http\Literal::class,
    'options' => [
        'route'    => '/',
        'defaults' => [
            'controller' => AlbumController::class, // <-- change here
            'action'     => 'index',
        ],
    ],
],
```

就是这样 - 你现在有一个完整的应用程序！
