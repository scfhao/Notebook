PHP 允许您从脚本直接发送电子邮件。

PHP mail()函数用于从脚本中发送电子邮件。

语法：

mail(to,subject,message,headers,parameters)

参数 | 描述
----|------
to | 必需。规定email接收者。
subject | 必需。规定email的主题。注释：该参数不能包含任何新行字符。
message | 必需。定义要发送的消息。应该用LF(\n)来分隔各行。
headers | 可选。规定附加的标题，比如From，Cc以及Bcc。应当使用CRLF(\r\n)分隔附加的标题。
parameters | 可选。对邮件发送程序规定额外的参数。

注释：PHP需要一个已安装且正在运行的邮件系统，以便邮件函数可用。所用的程序通过在php.ini文件中的配置设置进行定义。

一个例子：

```
<?php
if (isset($_REQUEST['email']))
//if "email" is filled out, send email
  {
  //send email
  $email = $_REQUEST['email'] ; 
  $subject = $_REQUEST['subject'] ;
  $message = $_REQUEST['message'] ;
  mail("someone@example.com", "Subject: $subject",
  $message, "From: $email" );
  echo "Thank you for using our mail form";
  }
else
//if "email" is not filled out, display the form
  {
  echo "<form method='post' action='mailform.php'>
  Email: <input name='email' type='text' /><br />
  Subject: <input name='subject' type='text' /><br />
  Message:<br />
  <textarea name='message' rows='15' cols='40'>
  </textarea><br />
  <input type='submit' />
  </form>";
  }
?>
```

以上代码存在的问题是，未经授权的用户可通过输入表单在邮件头部插入数据。假如用户在表单中的输入框内加入这些文本，会出现什么情况呢？

```
someone@example.com%0ACc:person2@example.com
%0ABcc:person3@example.com,person3@example.com,
anotherperson4@example.com,person5@example.com
%0ABTo:person6@example.com
```

与往常一样，mail() 函数把上面的文本放入邮件头部，那么现在头部有了额外的 Cc:, Bcc: 以及 To: 字段。当用户点击提交按钮时，这封 e-mail 会被发送到上面所有的地址！

防止E-mail注入的最好方法是对输入进行验证。一个验证函数：

```
function spamcheck($field)
  {
  //filter_var() sanitizes the e-mail 
  //address using FILTER_SANITIZE_EMAIL
  $field=filter_var($field, FILTER_SANITIZE_EMAIL);
  
  //filter_var() validates the e-mail
  //address using FILTER_VALIDATE_EMAIL
  if(filter_var($field, FILTER_VALIDATE_EMAIL))
    {
    return TRUE;
    }
  else
    {
    return FALSE;
    }
  }
```

在上面的代码中，使用了PHP过滤器来对输入进行验证：

* FILTER_SANITIZE_EMAIL 从字符串中删除点子邮件的非法字符
* FILTER_VALIDATE_EMAIL 验证电子邮件地址
