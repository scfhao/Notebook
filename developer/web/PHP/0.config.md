# Mac自带的php配置

## Apache 配置

1. 修改Apache配置文件`/private/etc/apache2/httpd.conf`，保证如下配置没被注释：
LoadModule php5_module libexec/apache2/libphp5.so

2. 重启Apache

## MySQL 配置

### localhost 与 127.0.0.1

连接 MySQL 时，使用 localhost 和使用 127.0.0.1 是有区别的，使用 localhost时，默认是通过 Unix Socket 进行连接，使用 127.0.0.1 时，是用 TCP 进行连接，用 Unix Socket 连接效率较高，但 Unix Socket 需要配置才能工作。（如果不配置则表现为：使用 127.0.0.1 可以连接数据库，但使用 localhost 无法连接数据库）

配置方法如下：

先查看本机 MySQL 的 socket 套接字文件在哪里，命令如下：

$ mysqld --verbose --help | grep socket
[输出]: socket   /var/run/mysqld/mysqld.sock

在PHP的配置文件（/etc/php.ini）中设置MySQL的套接字位置(这个值默认是空的)：

mysql.default_socket = /var/run/mysqld/mysqld.sock

### 默认时区

date.timezone = Asia/Shanghai
