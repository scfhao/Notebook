# 起由

Discuz是一个第三方论坛，之间见过多个论坛是基于Discuz的，如黑马程序员的论坛、威锋网论坛。

Discuz的代码可以自行下载，我从大学同学处得到的此PHP版本代码。正好前段时间自学了几天PHP，Discuz对于我可能是最好的学习对象了。

我本地的Discuz版本为：Discuz! X3.2 Release 20160601

+----------------------------------+
 Discuz! X 社区软件的环境需求
+----------------------------------+
1. 可用的 www 服务器，如 Apache、Zeus、IIS 等
2. php 4.3.0 及以上
3. Zend Optimizer 2.5.7 及以上
4. MySQL 3.23 及以上，仅针对 MySQL 版

+----------------------------------+
 我的本地环境
+----------------------------------+
1. OS: macOS Sierra
2. Server: Apache2 (由macOS自带)
3. php: PHP 5.6.27 (由macOS自带)
4. Zend Optimizer: Zend Engine v2.6.0
5. MySQL: 

+----------------------------------+
 Discuz! X 社区软件的安装 [图文教程](http://www.discuz.net/thread-3258186-1-1.html)
+----------------------------------+
1. 上传 upload 目录中的文件到服务器
2. 设置目录属性（windows 服务器可忽略这一步）
	以下这些目录需要可读写权限
	./config
	./data 含子目录
3. 执行安装脚本 /install/
   请在浏览器中运行 install 程序，即访问 http://您的域名/论坛目录/install/
4. 参照页面提示，进行安装，直至安装完毕

一步一步安装
上传upload目录到服务器的文档目录后，访问server，自动出现了安装向导，同意协议后
