在创建项目时，Interface 选择“SwiftUI”后，项目中会有一个名为“项目名+App”的 Swift 文件，文件内容如下：

```Swift
import SwiftUI

@main
struct LandmarksApp: App {
	var body: some Scene {
		WindowGroup {
			ContentView()
		}
	}
}
```

使用 SwiftUI App生命周期的应用有一个遵循 App 协议的结构。这个结构的 body 属性返回一个或多个场景，用于提供显示的内容。@main 属性标识应用的总入口。

默认情况下，SwiftUI 的视图文件定义一个结构和一个预览。这个结构遵循 View 协议，定义视图的内容和布局。预览则为这个视图创建一个预览。

```Swift
import SwiftUI

struct ContentView: View {
    var body: some View {
        VStack {
            Image(systemName: "globe")
                .imageScale(.large)
                .foregroundStyle(.tint)
            Text("Hello, world!")
        }
        .padding()
    }
}

#Preview {
    ContentView()
}
```

花布默认为 Live 模式，这时你可以与它进行交互。你可以可以把它切换到 Selectable 模式来让它变为可编辑的。

在 Selectable 模式下，Command-Control-click 一个元素，然后在弹出的菜单中选择“Show SwiftUI Inspector”，会在画布中弹出属性修改器页面。根据元素的类型不同，可修改的属性也不同。

同样，可以在代码中通过 Control-clicking 代码中的元素声明，然后在弹出菜单中选择“Show SwiftUI Inspector”来弹出属性修改器弹窗。

使用 Stack 组合元素的例子：

```SwiftUI
struct ContentView: View {
    var body: some View {
        VStack(alignment: .leading) {
            Text("Turtle Rock")
                .font(.title)
            HStack {
                Text("Joshua Tree National Park")
                    .font(.subheadline)
                Spacer()
                Text("California")
                    .font(.subheadline)
            }
        }
        .padding()
    }
}
```

## 创建自定义视图

创建一个应用了遮罩、圆角、阴影的图片视图。

完成的代码如下：

```Swift
import SwiftUI

struct CircleImage: View {
    var body: some View {
        Image("turtlerock")
            .clipShape(Circle())
            .overlay {
                Circle().stroke(.white, lineWidth: 4)
            }
            .shadow(radius: 7)
    }
}

#Preview {
    CircleImage()
}
```

## 在 SwiftUI 中使用其他框架中的视图

以 MapKit 框架中的 MKMapView 为例。

完成的代码如下：

```Swift
import SwiftUI
import MapKit

struct MapView: View {
    var body: some View {
        Map(initialPosition: .region(region))
    }
    
    private var region: MKCoordinateRegion {
        MKCoordinateRegion(
            center: CLLocationCoordinate2D(latitude: 34.011_286, longitude: -116.166_868), span: MKCoordinateSpan(latitudeDelta: 0.2, longitudeDelta: 0.2)
        )
    }
}

#Preview {
    MapView()
}
```

当你在像 stack 这样的布局视图上添加修饰器时，SwiftUI 会应用这些修饰器到它包含的这组元素上。
