# 日历和提醒介绍

> 重要：本文档不再更新。关于 Apple SDK 的最新信息，访问[文档网站](https://developer.apple.com/documentation)。

EventKit 框架可以帮助你访问用户的日历和提醒数据。尽管是用两个不同的应用展示用户的日历和提醒数据，但他们使用的是同一个框架。同样的，在被称为日历数据库的数据库中同时存储了日历和提醒信息。

图 1-1 EventKit 结构

> 重要：在 iOS 10.0 之后，应用必须在它的 Info.plist 文件中包含要访问数据的用途，否则应用会闪退。要访问提醒和日历，需要分别包含`NSRemindersUsageDescription`和`NSCalendarsUsageDescription`。
> 所有要访问用户的日历数据的 OS X 沙盒应用必须包含`com.apple.security.personal-information.calendars`实体。更多应用沙盒相关的实体内容，参见[允许应用沙盒](https://developer.apple.com/library/archive/documentation/Miscellaneous/Reference/EntitlementKeyReference/Chapters/EnablingAppSandbox.html#//apple_ref/doc/uid/TP40011195-CH4-SW4)。
