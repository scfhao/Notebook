# 用 dumpdecrypted 给 App 砸壳

[dumpdecrypted](https://github.com/stefanesser/dumpdecrypted)

1. 找到目标 App 的可执行文件目录
可以使用`ps -e`命令从运行的进程列表中看到。

2. 找到目标 App 的 Documents 目录
可以使用 cycript 命令`cycript -p TargetApp`

3. 把编译过的dumpdecrypted.dylib 复制到该 Documents 目录下（考虑到沙盒权限问题，放这里比较好，别的地方权限会有问题，也有直接把这个文件放到 iOS 设备的 `/usr/bin`下的，可以尝试一下）

4. 开始砸壳，（新系统需要在以 mobile 用户执行此操作，可以通过`su mobile`命令切换到 mobile 用户）：
```
DYLD_INSERT_LIBRARIES=dumpdecrypted.dylib /var/mobile/Applications/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/Scan.app/Scan
...
```

会生成一个TargetApp.decrypted，然后可以用 class-dump 对其进行静态分析了。

## 注意事项

如果遇到Abort trap: 6的错误，可能是因为你要砸的应用在编译的时候加了restricted Mach-O 中加入了 restrict 字段，不允许动态库的插入.
