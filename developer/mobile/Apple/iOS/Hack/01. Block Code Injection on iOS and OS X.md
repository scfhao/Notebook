想要阻止动态Hooking你的应用可以在“Other Linker Flags”中增加`-Wl, -sectcreate, __RESTRICT, __restrict, /dev/null`

dyld macOS 和 iOS 上的动态连接器，有一些环境变量可以修改其行为，[其环境变量列表](https://developer.apple.com/legacy/library/documentation/Darwin/Reference/ManPages/man1/dyld.1.html)，其中最常用的环境变量就是`DYLD_INSERT_LIBRARIES`

当应用程序启动时，二进制文件通过dyld运行，并处理二进制文件。 这找到需要加载和链接的库来生成完整的符号表。 这样做需要解析二进制头，而它可以根据二进制中存在哪些段来触发dyld中的标志。 有一个特殊的标志将被设置为被标记为“限制”的二进制文件。 这个特殊标志意味着动态链接器应该忽略任何设置的环境变量。

有三种方式可以将二进制向动态连接器标记为"restricted"

1. 通过 entitlements 文件设置 restricted 状态。
	这个选项只支持 macOS 上有特殊授权的应用。
2. setuid 和 setgid
	Any application that makes these two calls are going to be marked as restricted by the linker as a security measure.
3. 在头（二进制头）中限制
	告诉连接器在二进制头中增加 __RESTRICT 和 __restrict 组。这就是通过在 Xcode 中的 Other Linker Flags 中增加`-Wl,-sectcreate,__RESTRICT,__restrict,/dev/null`

注意

* 只在生产版本中添加这个设置，如果在开发版本中做了这样的设置，在使用Instruments, guard malloc和第三方有库注入的调试工具时会有问题。
