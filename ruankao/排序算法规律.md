# 常见排序算法时间、空间复杂度

## 1. 时间复杂度

- O(n^2)：冒泡、选择、插入，直观但效率低
- O(nlogn)：快速、归并、堆排序，高效排序主力军
- O(n)：桶排序、基数排序、桶排序

## 2. 空间复杂度

- O(1)：原地排序。冒泡、选择、插入、希尔、堆
- O(n)：归并、计数/桶/基数，需要额外空间
- O(log n)：快速

## 3. 稳定性

- 稳定：冒泡、插入、归并、计数/桶/基数
- 不稳定：选择、快速、希尔、堆

## 4. 适用场景

- 数据量小或基本有序：插入排序
- 追求通用最高效率：快速排序
- 要求稳定且效率高：归并排序
- 数据是整数且范围小：计数排序
- 担心快排的最坏情况：堆排序能保证O(n log n)
