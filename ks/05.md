題目背景
你需開發一個「待辦事項」應用，使用 Vue 3 組合式 API（<script setup>）以及封裝好的 Axios 請求模組。後端 API 已提供：
GET /api/todos → 取得所有待辦事項
POST /api/todos → 新增待辦事項（{ title, completed }）
PUT /api/todos/:id → 更新事項（可修改 title 或 completed）
DELETE /api/todos/:id → 刪除事項

要求實作以下功能：
頁面載入時顯示載入中狀態，從後端取得事項清單並顯示。
可新增事項（輸入框 + 新增按鈕，非同步請求，成功後重新載入清單）。
可切換事項的完成狀態（點擊核取方塊，立即更新到後端）。
可刪除事項（點擊刪除按鈕，彈出確認後非同步刪除，成功後更新清單）。
統一錯誤處理：所有請求失敗時顯示 alert 錯誤訊息。
使用 async/await 搭配 try/catch 處理非同步操作。
