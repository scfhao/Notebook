【場景描述】
你需要實現一個「查詢用戶列表」的功能。
後端 (Java)：接收前端傳來的 page 和 size 參數，調用數據庫查詢，並返回統一的 JSON 格式 {code, msg, data}。
前端 (JS)：使用 Axios 發送請求，並將獲取的數據渲染到頁面上。

---

1. setData
技術點：Lombok @Data 註解會自動生成 Getter/Setter 方法，這裡用於填充統一響應體中的數據字段。
2. getPage (或 getUserPage，視具體 Service 接口定義而定)
技術點：Controller 層調用 Service 層進行業務邏輯處理，實現分層架構。
3. success
技術點：使用靜態工廠方法構建標準的 API 響應格式，規範前後端交互協議。
4. Page
技術點：MyBatis-Plus 提供的分頁插件核心類，用於封裝分頁參數和結果。
5. selectPage
技術點：MyBatis-Plus BaseMapper 提供的內置分頁查詢方法，自動處理 SQL 的 LIMIT 語句。
JavaScript 部分答案
6. ref
技術點：Vue 3 Composition API 的核心，用於定義基礎類型的響應式數據。
7. get
技術點：Axios 庫發送 HTTP GET 請求的方法，支持傳遞 params 查詢參數。
8. records
技術點：MyBatis-Plus 分頁對象 Page<T> 序列化後，數據列表通常位於 records 字段中。
9. getUserList
技術點：Vue 的生命週期鉤子 onMounted，用於在組件掛載完成後立即執行數據獲取邏輯。
10. click
技術點：Vue 的事件綁定指令 v-on 的縮寫 @，用於監聽 DOM 點擊事件並觸發 JS 函數。
