setData
技术点：Lombok @Data 注解生成的 Setter 方法，用于填充统一响应体中的 data 字段。
proceed
技术点：AOP 环绕通知 (@Around) 中，通过 ProceedingJoinPoint.proceed() 方法放行并执行被拦截的目标方法。
setIfAbsent
技术点：Spring Data Redis (StringRedisTemplate) 中对应 Redis SETNX 命令的方法，是实现分散式锁的核心。
insert
技术点：MyBatis-Plus BaseMapper 提供的内置方法，用于向数据库插入一条记录。
convertAndSend
技术点：Spring AMQP (RabbitTemplate) 中用于发送消息的标准方法，参数分别为交换机名称、路由键和消息内容。
error
技术点：调用统一响应类中定义的静态失败方法，封装错误码和错误信息。
@RabbitListener
技术点：Spring AMQP 提供的核心注解，用于标识一个方法为消息监听器，自动消费指定队列的消息。
stock_exchange
技术点：RabbitMQ 的交换机（Exchange）名称，消费者绑定的交换机必须与生产者发送时的名称完全一致。
stock.reduce
技术点：RabbitMQ 的路由键（Routing Key），在 Topic 交换机模式下，绑定的路由键需与发送时匹配。
@PostMapping
技术点：Spring Web 提供的注解，用于将 HTTP POST 请求映射到特定的处理器方法上（等同于 @RequestMapping(method = RequestMethod.POST)）。
