
題目背景
需要開發一個簡單的「待辦事項」應用，具備以下功能：
新增任務：從輸入框取得文字，建立任務項目並顯示在清單中，同時儲存到 localStorage
刪除任務：每個任務旁有一個刪除按鈕，點擊後移除該任務
標記完成：點擊任務文字可切換完成狀態（加上刪除線樣式）
過濾任務：三個按鈕「全部」「未完成」「已完成」，點擊後只顯示對應狀態的任務
資料持久化：頁面載入時從 localStorage 讀取任務，新增/刪除/切換狀態時同步更新儲存

填空 1
!t.completed 和 t.completed
說明：active 篩選未完成（completed = false），completed 篩選已完成。
填空 2
id, text, completed
說明：從 task 物件中解構出三個屬性。
填空 3
id
說明：閉包內層函數需要接收外層傳入的 id 參數，此處填 id。
填空 4
id
說明：過濾掉 id 相符的任務。
填空 5
[...tasks, newTask]
說明：展開原 tasks 陣列並加入新任務。
填空 6
btn.dataset.filter
說明：取得自定義屬性 data-filter 的值。
填空 7
JSON.parse(stored)
說明：將 JSON 字串轉回物件陣列。
填空 8
resolve
說明：呼叫 resolve 將 Promise 狀態變為 fulfilled。
填空 9
msg
說明：then 的回呼參數接收 resolve 傳遞的值。
填空 10
count++ 或 count += 1
說明：每次呼叫增加計數並回傳。
