# 考前易錯速記

1. 語句覆蓋最弱；路徑覆蓋最強。  
2. 滿足 CDC 一定滿足條件覆蓋與判定覆蓋。  
3. MCDC 用於高安全系統，測短路行為，用例數常為條件數＋1。  
4. `@AfterAll` 是所有測試後一次；`@AfterEach` 是每個測試後。  
5. Mockito：`verify` 驗互動；`doReturn` 適合 Spy；`ArgumentCaptor` 抓參數。  
6. `finally` 幾乎一定執行；字串比較用 `equals()`。  
7. 組合優於繼承；依賴抽象，不依賴細節。  
8. SQL 注入最有效防範是參數化查詢。  
9. Kafka 同一分區只能被同群組一個消費者消費。  
10. Redis 同時開 RDB＋AOF，優先載入 AOF。
