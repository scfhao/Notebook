SQL 基礎查詢與窗口函數進階應用（複雜業務場景）
題目背景
你是一家連鎖零售企業的數據分析師。資料庫包含以下四張表：
-- 部門表
CREATE TABLE departments (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    region VARCHAR(50) NOT NULL      -- 區域：『北區』、『南區』、『東區』
);

-- 員工表
CREATE TABLE employees (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    department_id INT REFERENCES departments(id),
    salary DECIMAL(10,2) NOT NULL,
    hire_date DATE NOT NULL,
    performance_score INT            -- 績效評分 (1~10, 允許 NULL)
);

-- 訂單表
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    employee_id INT REFERENCES employees(id),
    order_amount DECIMAL(12,2) NOT NULL,
    order_date DATE NOT NULL
);

-- 銷售目標表
CREATE TABLE sales_targets (
    id SERIAL PRIMARY KEY,
    department_id INT REFERENCES departments(id),
    target_month DATE NOT NULL,      -- 每月第一日
    target_amount DECIMAL(12,2) NOT NULL
);
業務需求（須以單一 SQL 完成，不可拆分為多個查詢）：
查詢 2024 年第一季（1~3 月） 各部門的以下指標：
部門名稱、區域
部門總訂單金額
部門總訂單金額 佔全公司總訂單金額的百分比（使用窗口函數）
部門內 業績最高員工 的姓名與訂單金額
該部門是否達成當月目標（需與 sales_targets 比對，任意一個月未達成即標記為『未達標』）
對全體員工按以下規則進行綜合排名：
基礎權重：績效評分佔 40%，訂單總額佔 60%
若績效評分為 NULL，則視為 0 分
總分相同時，按訂單總額降序、薪資升序決定名次
使用 DENSE_RANK() 產生連續排名
計算每個員工 相對於同部門前一筆訂單 的金額增長率（%），並只顯示增長率 > 20% 的記錄。
找出 連續三個月訂單金額均高於部門平均 的員工。

填空 1
SUM(SUM(o.order_amount)) OVER ()
說明：內層 SUM 按部門分組，外層 SUM OVER () 計算全公司總額。

填空 2
SUM(o2.order_amount) DESC NULLS LAST
說明：確保無訂單的員工（SUM 為 NULL）排到最後，避免影響 LIMIT 1 的結果。

填空 3
完整子查詢應補齊：
SELECT 1 
FROM sales_targets st
WHERE st.department_id = d.id 
  AND st.target_month BETWEEN '2024-01-01' AND '2024-03-01'
  AND st.target_amount > (
      SELECT COALESCE(SUM(o3.order_amount), 0)
      FROM orders o3
      JOIN employees e3 ON o3.employee_id = e3.id
      WHERE e3.department_id = d.id
        AND o3.order_date >= st.target_month
        AND o3.order_date < st.target_month + INTERVAL '1 month'
  )
說明：逐月比對，若目標 > 實際則該月未達標，EXISTS 只要存在一個未達標月份即整體未達標。

填空 4
LOG(10, total_orders + 1) * 0.6
說明：對數縮放，加 1 避免 LOG(0)，權重仍為 0.6。

填空 5
salary ASC
說明：同分時薪資較低者排名更靠前（升序）。

填空 6
LAG(order_amount) OVER (PARTITION BY employee_id ORDER BY order_date)
說明：省略第三個參數時預設為 NULL。

填空 7
100.0 * (order_amount - prev_amount) / prev_amount
說明：使用 prev_amount 別名，避免重複計算 LAG。

填空 8
dept_monthly_avg AS (

    FROM monthly_emp
    GROUP BY department_id, mon

說明：先聚合員工月度金額，再按部門+月份求平均。

填空 9
ROWS BETWEEN 2 PRECEDING AND CURRENT ROW

填空 10
