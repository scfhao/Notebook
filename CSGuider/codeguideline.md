C语言番外：如何写出更规范的代码

各位读者，好久不见呀！今天我们聊一聊代码规范的问题。

C 语言可能是绝大多数计算机相关专业的学生接触到的第一门编程语言，所以在看一些同学写的代码时，常常会比较抓狂。比较常见有缩进的问题、换行的问题、空格的问题、变量名/函数名中英文乱写的问题、注释的问题等。

和文章一样，代码也是写给人看的。给老师看，给共同协作的同学看，或者给未来的自己看。除非你说，你写的这段代码不会给任何人看，只用于给机器执行，而且以后也不会再迭代升级这段代码，那你可以随便写。

在一些比较“新”的编程语言里，会从语法层次对代码格式做要求，比如在 Python 中，代码块外面不需要像 C 语言里有花括号，而是根据缩进来确定代码块的开始结束位置。
